### Teil 2: Mengen

**In einem Satz:** Eine Menge ist eine Sammlung verschiedener Dinge, bei der es nur darauf ankommt, **ob** etwas
dazugehört, nicht in welcher Reihenfolge oder wie oft.

**Stell dir vor:** Zwei Einkaufszettel. A = {Milch, Brot, Eier}, B = {Brot, Käse}. „Was steht auf mindestens einem
Zettel?“ ist die Vereinigung. „Was steht auf beiden?“ ist der Schnitt.

**Mit Zahlen:** A = {1, 2, 3, 4}, B = {3, 4, 5}

| Operation | Zeichen | Auf Deutsch | Ergebnis |
|---|---|---|---|
| Vereinigung | A ∪ B | in A **oder** in B | {1, 2, 3, 4, 5} |
| Schnitt | A ∩ B | in A **und** in B | {3, 4} |
| Differenz | A \ B | in A, aber **nicht** in B | {1, 2} |
| Differenz andersrum | B \ A | in B, aber nicht in A | {5} |
| symmetrische Differenz | A △ B | in genau einer der beiden | {1, 2, 5} |

**Weitere Begriffe:**
- **x ∈ A** heißt „x liegt in A“, **x ∉ A** heißt „x liegt nicht in A“.
- **A ⊆ B** (Teilmenge) heißt: Jedes Element von A liegt auch in B. Beispiel: {3, 4} ⊆ {3, 4, 5}.
- **∅** ist die leere Menge. Sie ist Teilmenge **jeder** Menge.
- **|A|** ist die Mächtigkeit, also die Anzahl der Elemente: |{1, 2, 3, 4}| = 4.
- **Komplement** Aᶜ = G \ A, alles aus der Grundmenge G, was nicht in A ist.
- **Potenzmenge** 𝒫(A) ist die Menge **aller** Teilmengen. 𝒫({1, 2}) = {∅, {1}, {2}, {1, 2}}. Allgemein gilt
  |𝒫(A)| = 2^|A|, also hat {1, 2, 3} 2³ = 8 Teilmengen.
- **Kartesisches Produkt** A × B ist die Menge aller Paare (a, b). {1, 2} × {a, b, c} hat 2 · 3 = 6 Paare:
  (1, a), (1, b), (1, c), (2, a), (2, b), (2, c).

**Die Brücke zur Logik:** Mengenoperationen sind Logik mit „x ∈ …“:
- x ∈ A ∪ B ⇔ x ∈ A ∨ x ∈ B
- x ∈ A ∩ B ⇔ x ∈ A ∧ x ∈ B
- A ⊆ B ⇔ ∀x: x ∈ A → x ∈ B

Deshalb gelten die Gesetze aus Kapitel 1 auch für Mengen, zum Beispiel **De Morgan**: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ und
(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ.

**Mengengleichheit beweisen:** Zeige beide Richtungen, also A ⊆ B **und** B ⊆ A. Oder du formst mit den Logikgesetzen
um: x ∈ (A ∪ B)ᶜ ⇔ ¬(x ∈ A ∨ x ∈ B) ⇔ x ∉ A ∧ x ∉ B ⇔ x ∈ Aᶜ ∩ Bᶜ.

### Teil 3 (falls die Zeit reicht): Relationen und Abbildungen

- Eine **Relation** von A nach B ist eine Teilmenge von A × B, also eine Liste von Paaren, die „in Beziehung“
  stehen. Beispiel: „≤“ auf {1, 2, 3}.
- Eigenschaften einer Relation R auf M:
  - **reflexiv:** (x, x) ∈ R für alle x
  - **symmetrisch:** aus (x, y) ∈ R folgt (y, x) ∈ R
  - **antisymmetrisch:** aus (x, y) und (y, x) folgt x = y
  - **transitiv:** aus (x, y) und (y, z) folgt (x, z)
- **Äquivalenzrelation** = reflexiv + symmetrisch + transitiv, zum Beispiel „hat denselben Rest bei Division durch 3“.
- Eine **Abbildung** f: A → B ordnet jedem a ∈ A genau ein f(a) ∈ B zu. Sie ist **injektiv**, wenn nie zwei auf
  dasselbe Ziel gehen, **surjektiv**, wenn jedes Ziel getroffen wird, und **bijektiv**, wenn beides gilt (dann gibt
  es eine Umkehrabbildung). Das kennst du schon aus dem Analysis-Teil.

## Wichtige Begriffe
- **Element (∈)** – x gehört zur Menge
- **Teilmenge (⊆)** – alles aus A liegt auch in B
- **Vereinigung / Schnitt / Differenz (∪ / ∩ / \\)** – oder / und / „ohne“
- **Komplement (Aᶜ)** – alles aus der Grundmenge außer A
- **Potenzmenge (𝒫(A))** – alle Teilmengen, 2^|A| Stück
- **Kartesisches Produkt (A × B)** – alle Paare, |A| · |B| Stück
- **Relation** – Teilmenge von A × B
- **Äquivalenzrelation** – reflexiv, symmetrisch, transitiv

## Aufgaben / Übungen
1. A = {1, 2, 3, 4}, B = {3, 4, 5}: Berechne A ∪ B, A ∩ B, A \ B und B \ A.
2. Wie viele Elemente hat 𝒫({1, 2, 3})? Schreib alle auf.
3. Ist R = {(1,1), (2,2), (3,3), (1,2), (2,1)} auf M = {1, 2, 3} eine Äquivalenzrelation?
4. Zeige mit Logikgesetzen: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ.

**Lösungen**
1. {1, 2, 3, 4, 5}; {3, 4}; {1, 2}; {5}.
2. 2³ = 8: ∅, {1}, {2}, {3}, {1, 2}, {1, 3}, {2, 3}, {1, 2, 3}.
3. Ja. Reflexiv: (1,1), (2,2), (3,3) sind drin. Symmetrisch: zu (1,2) gibt es (2,1). Transitiv: (1,2) und (2,1)
   ergeben (1,1), das ist drin; alle anderen Kombinationen ebenfalls (mit Python über alle Paare geprüft).
4. x ∈ (A ∪ B)ᶜ ⇔ ¬(x ∈ A ∨ x ∈ B) ⇔ (x ∉ A) ∧ (x ∉ B) ⇔ x ∈ Aᶜ ∩ Bᶜ (De Morgan aus der Logik).
