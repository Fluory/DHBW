## Zusammenfassung

### 1. Von der Sekante zur Tangente
- **Idee (Linearisierung):** Eine komplizierte Funktion wird in der Nähe einer Stelle x₀ durch eine Gerade ersetzt,
  die dort dieselbe Steigung hat. Folienbeispiel: Investmentbanken schätzen damit, wie sich ein Unternehmenswert
  ändert, wenn der Umsatz steigt.
- **Differenzenquotient** = (f(x) − f(x₀)) / (x − x₀), oder mit h = x − x₀: (f(x₀ + h) − f(x₀)) / h. Das ist die
  Steigung der **Sekante** durch zwei Punkte des Graphen.
- **Ableitung** f′(x₀) = Grenzwert des Differenzenquotienten für x → x₀ (bzw. h → 0). Existiert er, heißt f in x₀
  **differenzierbar**. f′(x₀) ist die Steigung der **Tangente**.
- **Beispiel (Folie):** f(x) = x². (f(x₀ + h) − f(x₀)) / h = (2x₀h + h²) / h = 2x₀ + h → 2x₀. Also f′(−4) = −8,
  f′(0) = 0, f′(3) = 6.
- **Tangente:** g(x) = f(x₀) + f′(x₀) · (x − x₀).
- **Ökonomisch:** f′ ist die **lokale Änderungsrate**. K′(x) = Grenzkosten (Kosten einer zusätzlichen Einheit),
  R′(x) = Grenzerlös. Einheit von f′ = Einheit von f / Einheit von x.

### 2. Stetigkeit und Differenzierbarkeit
- **Differenzierbar ⇒ stetig**, aber **nicht umgekehrt**.
- **Gegenbeispiel:** |x| ist in 0 stetig, aber nicht differenzierbar: Von links ist die Steigung −1, von rechts +1.
- **Stetige Fortsetzung:** (x² − 1) / (x − 1) = x + 1 für x ≠ 1, also mit f(1) = 2 stetig fortsetzbar.

### 3. Ableitungsfunktion und höhere Ableitungen
- Existiert f′(x₀) überall, ist f′ selbst eine Funktion (Ableitungsfunktion), z. B. (x²)′ = 2x.
- f″ = (f′)′ usw. **Bei Kosten:** K′ = Grenzkosten, K″ = Änderung der Grenzkosten.
- **Folienbeispiel:** K(x) = x³ − 6x² + 15x + 10 → K′(x) = 3x² − 12x + 15, K″(x) = 6x − 12, K″ = 0 bei x = 2
  (Wendepunkt).

### 4. Ableitungsregeln
- **Linearität:** (c · f + d · g)′ = c · f′ + d · g′; Konstante → 0.
- **Produktregel:** (f · g)′ = f′ · g + f · g′. Achtung: (f · g)′ ≠ f′ · g′.
- **Quotientenregel:** (f / g)′ = (f′ · g − f · g′) / g². Merkspruch: „Ableitung oben mal unten minus oben mal
  Ableitung unten, durch unten zum Quadrat.“
- **Kettenregel:** (g ∘ f)′(x) = g′(f(x)) · f′(x), „äußere mal innere Ableitung“.
- **Grundfunktionen:** xⁿ → n · xⁿ⁻¹ · eˣ → eˣ · aˣ → aˣ · ln a · ln x → 1/x · sin → cos · cos → −sin.
- **Folienbeispiele mit Ergebnis:**
  - 3x⁴ − 2x² + 7x − 5 → 12x³ − 4x + 7
  - (2x³ − x)(x² + 5) → (6x² − 1)(x² + 5) + (2x³ − x) · 2x = 10x⁴ + 27x² − 5
  - (x² − 1) / (x + 2) → (2x(x + 2) − (x² − 1)) / (x + 2)² = (x² + 4x + 1) / (x + 2)²
  - (x³ + 1)⁷ → 7(x³ + 1)⁶ · 3x² = 21x²(x³ + 1)⁶
  - cos(sin x) → −sin(sin x) · cos x
  - e^(x²) → 2x · e^(x²)

### 5. Extrema, Monotonie, Krümmung
- **Notwendig:** Ist x̂ ein lokales Extremum im Inneren, dann f′(x̂) = 0. Nicht hinreichend: x³ hat bei 0 einen
  **Sattelpunkt**.
- **Hinreichend:** f′(x₀) = 0 und f″(x₀) > 0 ⇒ **Minimum**; f″(x₀) < 0 ⇒ **Maximum**; f″(x₀) = 0 ⇒ keine Aussage.
  Alternativ: Vorzeichenwechsel von f′ (− zu + = Minimum, + zu − = Maximum).
- **Monotonie:** f′ ≥ 0 ⇔ monoton wachsend; f′ > 0 ⇒ streng monoton wachsend (umgekehrt nicht nötig).
- **Krümmung:** f″ ≥ 0 ⇔ konvex („Tal“), f″ ≤ 0 ⇔ konkav („Hügel“). Strikt konvex ⇒ höchstens ein Minimum, und das
  ist global.
- **Beispiel (Folie):** f(x) = x³ − 3x² + 2. f′(x) = 3x² − 6x = 3x(x − 2) = 0 bei x = 0 und x = 2.
  f″(x) = 6x − 6: f″(0) = −6 < 0 → **Maximum** (0 | 2), f″(2) = 6 > 0 → **Minimum** (2 | −2).
- **Beispiel (Folie):** f(x) = x³ − 3x + 2. f′ = 3x² − 3 = 0 bei x = ±1. f″(−1) = −6 → Maximum (−1 | 4),
  f″(1) = 6 → Minimum (1 | 0).

## Wichtige Begriffe
- **Differenzenquotient** – Steigung der Sekante
- **Ableitung / Differentialquotient** – Grenzwert des Differenzenquotienten, Steigung der Tangente
- **Grenzkosten** – K′(x), Kosten einer zusätzlichen Einheit
- **kritische Stelle** – f′(x₀) = 0
- **Sattelpunkt** – kritische Stelle ohne Extremum
- **konvex / konkav** – f″ ≥ 0 / f″ ≤ 0
