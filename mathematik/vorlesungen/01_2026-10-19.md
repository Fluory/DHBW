## Zusammenfassung

### Was ist eine Folge?
- Eine (reelle) **Folge** ist eine Funktion a: ℕ → ℝ, n ↦ aₙ, also eine geordnete Liste a₁, a₂, a₃, …
  Die Zahlen aₙ heißen **Glieder**, n heißt **Index** („Platznummer“).
- Der Index kann bei jeder ganzen Zahl beginnen (oft 0 oder 1), der Buchstabe ist beliebig (i, j, k, m, n).
- **Bildungsgesetz** = Vorschrift für das n-te Glied:
  - **explizit:** direkte Formel, z. B. aₙ = n², bₙ = (−1)ⁿ · 1/n, cₙ = 1/2ⁿ (ab n = 0)
  - **rekursiv:** aus Vorgängern, z. B. Fakultät a₁ = 1, aₙ = n · aₙ₋₁; Heron-Folge für √2:
    a₁ = 2, aₙ = ½ (aₙ₋₁ + 2/aₙ₋₁)
- **Alternierende Folge:** wechselndes Vorzeichen, meist durch den Faktor (−1)ⁿ.

**Praxisbeispiel – Pseudozufallszahlen (lineare Kongruenzmethode):** xₙ = (a · xₙ₋₁ + c) mod m mit
2 ≤ a < m, 0 ≤ c < m, 0 ≤ x₀ < m. Beispiel m = 9, a = 7, c = 4, x₀ = 3:
3, 7, 8, 6, 1, 2, **0, 4, 5**, 3, … (nachgerechnet).
⚠️ **Folienfehler:** Die Folie schreibt „3, 7, 8, 6, 1, 2, 5, 0, 4, 3“. Richtig ist x₆ = (7·2+4) mod 9 = 0,
x₇ = 4, x₈ = (7·4+4) mod 9 = 32 mod 9 = 5. Die Periode ist trotzdem 9. Nach spätestens m Schritten wiederholt sich
die Folge; in der Praxis m = 2³¹ − 1 für lange Perioden.
Bezug: mod und Rekursion kennst du aus Programmierung; das lässt sich in Python direkt nachprogrammieren.

### Monotonie
- **monoton wachsend:** aₙ ≤ aₙ₊₁ für alle n · **monoton fallend:** aₙ ≥ aₙ₊₁
- **streng** monoton wachsend/fallend: aₙ < aₙ₊₁ bzw. aₙ > aₙ₊₁ (echt größer/kleiner)
- Beispiele: n² streng wachsend · 1/n streng fallend · (−1)ⁿ **nicht monoton** (springt hin und her)
- Prüftechnik: Differenz aₙ₊₁ − aₙ (Vorzeichen) oder Quotient aₙ₊₁ / aₙ (bei positiven Gliedern, > 1 oder < 1)

### Beschränktheit
- **nach oben beschränkt:** es gibt K mit aₙ ≤ K für alle n · **nach unten beschränkt:** k ≤ aₙ für alle n
- **beschränkt** = beides, gleichwertig: |aₙ| ≤ C für alle n („Streifen“)
- Beispiele: 1/n beschränkt (0 < aₙ ≤ 1) · n² nur nach unten beschränkt (≥ 1) · (−1)ⁿ/n beschränkt (|aₙ| ≤ 1)

### Konvergenz
- **Definition:** aₙ konvergiert gegen a, wenn es zu **jedem** ε > 0 ein n₀ gibt, sodass **alle** Glieder ab n₀ im
  Intervall (a − ε, a + ε) liegen. Formal: ∀ε > 0 ∃n₀ ∈ ℕ: |aₙ − a| < ε für alle n ≥ n₀.
  Schreibweise: lim aₙ = a bzw. aₙ → a für n → ∞.
- Anschaulich: Man gibt eine Genauigkeit ε vor und findet einen Index, ab dem sie erreicht ist – für jedes noch so
  kleine ε. Es geht um „fast alle“ Glieder, nicht um einzelne.
- **Divergent** = nicht konvergent · **Nullfolge** = Grenzwert 0 · **bestimmt divergent** gegen +∞ / −∞, wenn die
  Glieder beliebig groß / klein werden.
- Beispiele: 1/n → 0 · 1 − 1/n → 1 · (½)ⁿ → 0 · (−1)ⁿ divergent (unbestimmt) · n² → +∞ (bestimmt divergent) ·
  (−1)ⁿ · n divergent (unbestimmt, wird betragsmäßig groß, aber mit wechselndem Vorzeichen).

### Eigenschaften konvergenter Folgen
- Der Grenzwert ist **eindeutig**.
- Jede konvergente Folge ist **beschränkt**.
- **Monotonie-Kriterium:** beschränkt + monoton (wachsend oder fallend) ⇒ konvergent.
- Grund-Nullfolgen: 1/n → 0 und qⁿ → 0 für |q| < 1.
- ⚠️ **Falle:** „divergent“ heißt **nicht** „unbeschränkt“ – (−1)ⁿ ist beschränkt, aber divergent. Und
  „beschränkt“ allein reicht nicht für Konvergenz, es braucht zusätzlich Monotonie.

### Rechenregeln für Grenzwerte
Wenn aₙ → a und bₙ → b: c · aₙ → c · a · aₙ ± bₙ → a ± b · aₙ · bₙ → a · b · aₙ / bₙ → a / b (falls b ≠ 0).
Damit zerlegt man komplizierte Folgen in Bausteine.

**Standardtrick bei Brüchen von Polynomen:** durch die **höchste Potenz des Nenners** kürzen.

- (2n² − 3)/(n² + n + 1) = (2 − 3/n²)/(1 + 1/n + 1/n²) → **2**
- (−5n + 1)/(4n² − 7) → **0** (Zählergrad < Nennergrad)
- Faustregel: Zählergrad = Nennergrad → Quotient der Leitkoeffizienten; Zählergrad < Nennergrad → 0;
  Zählergrad > Nennergrad → ±∞.
- 1/n + 2/n² → 0 · (3 + 100e⁻ⁿ) · 8 · (½)ⁿ → 3 · 8 · 0 = 0

### Arithmetische und geometrische Folgen
- **Arithmetisch:** konstante **Differenz** d. aₙ = a₁ + (n − 1) · d, rekursiv aₙ₊₁ = aₙ + d.
  Summe der ersten n Glieder: Sₙ = n/2 · (a₁ + aₙ).
  Beispiel a₁ = 3, d = 4: 3, 7, 11, …; a₁₀ = 3 + 9 · 4 = 39; S₁₀ = 5 · (3 + 39) = 210.
- **Geometrisch:** konstanter **Quotient** q. aₙ = a₁ · qⁿ⁻¹, rekursiv aₙ₊₁ = aₙ · q.
  Summe: Sₙ = a₁ · (qⁿ − 1)/(q − 1) (q ≠ 1).
  Beispiel a₁ = 2, q = 3: 2, 6, 18, …; a₈ = 2 · 3⁷ = 4374; S₆ = 2 · (729 − 1)/2 = 728.
- Ausblick: Geometrische Folgen/Reihen sind die Grundlage für Zinseszins und Renten (BWL/Finanzmathematik).

## Wichtige Begriffe

- **Folge, Glied, Index** – Funktion ℕ → ℝ / Wert aₙ / Platznummer n
- **explizites / rekursives Bildungsgesetz** – direkte Formel / aus Vorgängern
- **alternierend** – wechselndes Vorzeichen, Faktor (−1)ⁿ
- **(streng) monoton wachsend / fallend** – ≤ / < bzw. ≥ / >
- **beschränkt** – |aₙ| ≤ C für alle n
- **konvergent, Grenzwert, Nullfolge** – ∀ε ∃n₀: |aₙ − a| < ε
- **divergent / bestimmt divergent** – kein Grenzwert / gegen ±∞
- **Monotonie-Kriterium** – monoton + beschränkt ⇒ konvergent
- **arithmetische / geometrische Folge** – konstante Differenz d / konstanter Quotient q
- **lineare Kongruenzmethode** – Pseudozufallszahlen xₙ = (a · xₙ₋₁ + c) mod m
