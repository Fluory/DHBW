## Zusammenfassung

### Teil 1: Reihen

**1. Definition einer Reihe.** Eine Reihe ist der Versuch, unendlich viele Zahlen zu addieren:
Σₖ₌₀^∞ aₖ = a₀ + a₁ + a₂ + a₃ + … Der Startindex darf jede ganze Zahl sein (oft 0 oder 1), und der Buchstabe für den
Index ist egal (k, n, j …).

**2. Teilsummen und Konvergenz.** Man addiert Schritt für Schritt und schaut, wohin das läuft:
- s₀ = a₀, s₁ = a₀ + a₁, s₂ = a₀ + a₁ + a₂, allgemein sₙ = Σₖ₌₀ⁿ aₖ (die **Teilsummen**, auch Partialsummen).
- Kommen die Teilsummen einer Zahl s beliebig nahe, heißt die Reihe **konvergent** mit **Summe** s = lim sₙ.
  Sonst heißt sie **divergent**.
- Folien-Beispiele (Lösungen unten): Σ 1/2ᵏ = 2 (konvergent) · Σ 2ᵏ → ∞ (divergent) · harmonische Reihe Σ 1/k →
  ∞ (divergent).
- Wozu? Viele Konstanten wie e und π werden über Reihen definiert, und komplizierte Funktionen werden durch
  einfache Terme angenähert.

**3. Notwendiges Kriterium.** Σ aₖ konvergent ⇒ aₖ → 0. Die Umkehrung gilt **nicht**.
- Gehen die Summanden **nicht** gegen 0, ist die Reihe sofort divergent (Beispiel Σ 2ᵏ).
- Gehen sie gegen 0, weiß man noch **nichts** (Σ 1/k divergiert, Σ 1/k² konvergiert – beide haben Summanden → 0).

**4. Rechenregeln.** Sind Σ aₖ und Σ bₖ konvergent, dann darf man gliedweise rechnen:
Σ (c · aₖ) = c · Σ aₖ und Σ (aₖ ± bₖ) = Σ aₖ ± Σ bₖ.
Beispiel der Folie: Σₖ₌₁^∞ 6/k² = 6 · Σ 1/k² = 6 · π²/6 = **π²** ≈ 9,87.

**5. Warnung bei divergenten Reihen.** Mit divergenten Reihen darf man **nicht** wie mit normalen Summen rechnen.
Folien-Beispiel: Man tut so, als wäre 1 + 2 + 4 + 8 + … = x. Dann x = 1 + 2 · (1 + 2 + 4 + …) = 1 + 2x, also
x = −1. Unsinn: Lauter positive Zahlen ergeben nicht −1. Der Fehler: „x“ gibt es gar nicht, weil die Reihe
divergiert.

**6. Geometrische Reihe.** Σₖ₌₀^∞ qᵏ = 1 + q + q² + … (k steht im **Exponenten** einer festen Zahl q).
- Teilsummen: sₙ = (1 − qⁿ⁺¹)/(1 − q) für q ≠ 1.
- Für |q| < 1: qⁿ⁺¹ → 0, also **Σₖ₌₀^∞ qᵏ = 1/(1 − q)**. Für |q| ≥ 1 divergent.
- Startet die Summe nicht bei k = 0: **erstes Glied / (1 − q)**. Beispiel Σₖ₌₁^∞ (½)ᵏ = ½ / ½ = 1 (R-2 b).

**7. Periodenzahlen.** Jede periodische Dezimalzahl ist eine geometrische Reihe:
0,1̄ = 1/10 + 1/100 + … = (1/10) · 1/(1 − 1/10) = (1/10) · (10/9) = **1/9**. Überraschung der Folie: **0,9̄ = 1**
(9/10 · 10/9 = 1). Aufgabe R-3 übt das.

**8. Sparplan und ewige Rente.** Die geometrische Reihe ist die Grundlage der Finanzmathematik.
- Sparplan: n-mal r einzahlen, Zinssatz i pro Periode: **Eₙ = r · Σₖ₌₀ⁿ⁻¹ (1+i)ᵏ = r · ((1+i)ⁿ − 1)/i**
  (endliche geometrische Reihe mit q = 1 + i).
- Folien-Beispiel: r = 100 €, i = 0,25 % = 0,0025 pro Monat, n = 60 Monate:
  E₆₀ = 100 · (1,0025⁶⁰ − 1)/0,0025 ≈ 100 · 64,65 ≈ **6.464,67 €** (Folie rundet auf 6.460 €). Eingezahlt
  60 · 100 € = 6.000 €, also ca. 460 € Zinsen.
- Ewige Rente (Zahlung für immer, Barwert): **B∞ = Σₖ₌₁^∞ r/(1+i)ᵏ = r/i** (geometrisch mit q = 1/(1+i) < 1).
  Folien-Beispiel: r = 1.000 € pro Jahr, i = 4 % ⇒ B∞ = 1.000/0,04 = **25.000 €**.

### Teil 2: Reellwertige und stetige Funktionen

**1. Definition.** Eine Funktion f: D → W hat drei Teile, alle drei gehören dazu:
- **Definitionsmenge D:** alle x, die man einsetzen darf.
- **Wertemenge W:** eine Menge, in der alle Ergebnisse liegen.
- **Abbildungsvorschrift:** wie man aus x das f(x) berechnet, z. B. x ↦ x².
- Folien-Beispiele: Normalparabel x ↦ x² (ℝ → ℝ), h(z) = 1/(1 + z²), und eine **abschnittsweise** definierte
  Funktion (x² für 0 ≤ x < 1, Wert 2 bei x = 1, x − 1 für 1 < x ≤ 2).

**2. Bild.** Das **Bild** f(D) sind die Werte, die **wirklich** herauskommen. Die Wertemenge W darf größer sein.
Beispiel x²: ℝ → ℝ hat W = ℝ, aber Bild [0, ∞). Jedem x wird **genau ein** f(x) zugeordnet.

**3. Umkehrfunktion.** g = f⁻¹ macht f rückgängig: g(f(x)) = x und f(g(y)) = y.
- f⁻¹ ist **nicht** 1/f(x)!
- Existiert genau dann (auf dem Bild), wenn f **injektiv** ist; ist f zusätzlich surjektiv (bijektiv), dann auf ganz W.
- **Jede streng monotone Funktion hat eine Umkehrfunktion.**
- Bild: Graph von f an der Linie y = x spiegeln.
- Folien-Beispiel: f: [2, ∞) → ℝ, x ↦ x² − 4x + 1 ⇒ f⁻¹(x) = 2 + √(x + 3) (Mitschrift unten).

**4. Graph.** Graph(f) = alle Punkte (x, f(x)). **Vertikaltest:** Jede senkrechte Linie schneidet den Graphen
höchstens einmal, sonst ist es keine Funktion. Anschaulich beschreibt eine Funktion einen Zusammenhang, z. B.
verkaufte Stückzahl ⇒ Umsatz, produzierte Stückzahl ⇒ Kosten.

**5. Kombinationen.** f + g, f − g, f · g: definiert, wo **beide** definiert sind (D_f ∩ D_g). f/g: zusätzlich
**ohne** die Nullstellen von g. Beispiel f(x) = √x (D = [0, ∞)), g(x) = x − 1 (D = ℝ): f + g auf [0, ∞),
f/g auf [0, ∞) ohne 1. **Einschränkung** f|_A: dieselbe Vorschrift, nur auf einer kleineren Menge A.

**6. Verkettung.** (f ∘ g)(x) = f(g(x)): **zuerst g, dann f**. Voraussetzung: Was g ausgibt, muss f verarbeiten
können. Die Reihenfolge ist wichtig (f ∘ g ≠ g ∘ f). Beispiele der Folie in der Mitschrift (Folie 68).

**7. Beschränktheit.** f ist beschränkt, wenn es ein C gibt mit |f(x)| ≤ C für alle x. Auch „nach oben“ bzw.
„nach unten beschränkt“. Hängt vom **Definitionsbereich** ab: 1/x ist auf [1, ∞) beschränkt, auf (0, 1) nicht.

**8. Monotonie.** x < y ⇒ f(x) ≤ f(y) (monoton wachsend), f(x) < f(y) (streng wachsend), entsprechend fallend.
**Streng monoton ⇒ injektiv.** Rechenbeispiele der Folie (Folie 73) in der Mitschrift.

**9. Grenzwerte von Funktionen.** lim_{x→x̂} f(x) = y heißt: Für **jede** Folge xₙ → x̂ gilt f(xₙ) → y. So wird das
Folgenwissen wiederverwendet. Dazu einseitige Grenzwerte (x → x̂⁺ von rechts, x → x̂⁻ von links) und uneigentliche
(± ∞). Beispiele der Folie (Folie 75) in der Mitschrift.

**10. Stetigkeit.** f ist stetig in x̂, wenn lim_{x→x̂} f(x) = f(x̂). Anschaulich: kleine Änderung von x ⇒ kleine
Änderung von f(x); Graph „ohne Absetzen“ zeichnen. Beispiel der Folie: c so wählen, dass f stetig ist (c = 4/3,
Folie 79, Mitschrift).

**11. Stetige Funktionstypen.** Polynome (überall) · rationale Funktionen p/q (überall, wo q ≠ 0) ·
Potenzfunktionen x^(p/q) (auf (0, ∞), Wurzeln auf [0, ∞)) · exp, ln, sin, cos (auf ihrem ganzen
Definitionsbereich). Summe, Differenz, Produkt, c · f, Quotient (Nenner ≠ 0) und Verkettung stetiger Funktionen
sind wieder stetig.

**12. Unstetigkeiten – drei Typen.**
- **Sprungstelle:** links ≠ rechts. Beispiel f(x) = 1 für x ≥ 0 und −1 für x < 0: von links −1, von rechts 1.
- **Polstelle:** |f(x)| → ∞. Beispiel 1/(x − 2) bei x = 2: f(2,01) = 100, f(1,99) = −100.
- **Oszillationsstelle:** f schwingt immer schneller und kommt keinem Wert nahe. Beispiel sin(1/x) bei x = 0
  (Werte springen zwischen −1 und 1). Die Folie schreibt „unbeschränkte Schwankungen“; gemeint ist, dass die
  Schwankungen nicht kleiner werden – sin(1/x) selbst bleibt zwischen −1 und 1.
- **Wichtig:** Stetigkeit prüft man nur an Stellen **in** D. Eine Polstelle wie x = 2 bei 1/(x − 2) liegt außerhalb
  von D; die Funktion ist auf ihrem D trotzdem stetig.

## Wichtige Formeln / Rechenregeln (kompakt)
- Teilsumme sₙ = Σₖ₌₀ⁿ aₖ; Summe der Reihe = lim sₙ
- Notwendiges Kriterium: Σ aₖ konvergent ⇒ aₖ → 0; also aₖ ↛ 0 ⇒ divergent
- Rechenregeln: Σ (c·aₖ ± bₖ) = c·Σ aₖ ± Σ bₖ (nur wenn beide konvergieren)
- Geometrische Reihe: Σₖ₌₀^∞ qᵏ = 1/(1 − q) für |q| < 1; allgemein erstes Glied/(1 − q)
- Endliche geometrische Summe: Σₖ₌₀ⁿ qᵏ = (1 − qⁿ⁺¹)/(1 − q)
- Harmonische Reihe Σ 1/k divergiert; Σ 1/k² = π²/6 (Euler/„Riemann“); Σ 1/kᵖ konvergiert genau für p > 1
- Sparplan Eₙ = r · ((1+i)ⁿ − 1)/i · ewige Rente B∞ = r/i
- Kombinationen: D(f ± g) = D(f · g) = D_f ∩ D_g; D(f/g) zusätzlich ohne g(x) = 0
- Verkettung (f ∘ g)(x) = f(g(x)), zuerst g
- Stetig in x̂: lim_{x→x̂} f(x) = f(x̂)
- Streng monoton ⇒ injektiv ⇒ Umkehrfunktion existiert (auf dem Bild)
- Nicht auf den Folien, aber für R-1/R-4 nützlich: Quotientenkriterium lim |aₖ₊₁/aₖ| < 1 ⇒ konvergent

## Typische Fehler
- Folge der Summanden mit Folge der Teilsummen verwechseln („aₖ → 0, also Reihe = 0“ – falsch).
- Aus aₖ → 0 auf Konvergenz der Reihe schließen (harmonische Reihe!).
- Geometrische Reihe bei |q| ≥ 1 benutzen (1 + 2 + 4 + … = −1 – Unsinn, siehe Folienwarnung).
- Startindex vergessen: Σₖ₌₁^∞ (½)ᵏ = 1, nicht 2.
- Bei Periodenzahlen mit Vorlauf (4,312̄) die Periode falsch abgrenzen.
- f⁻¹(x) mit 1/f(x) verwechseln.
- Bei f/g die Nullstellen des Nenners nicht aus D herausnehmen.
- Bei der Verkettung die Reihenfolge vertauschen (f ∘ g heißt: zuerst g).
- Beim Kürzen (z. B. FU-2 c) vergessen, dass die gekürzte Stelle trotzdem **nicht** in D liegt.

## Wichtige Begriffe
- **Reihe** – Σ aₖ, definiert über die Folge der Teilsummen
- **Teilsumme** sₙ – Summe der ersten Glieder bis n
- **konvergent / divergent** – Teilsummen haben einen Grenzwert / keinen
- **notwendiges Kriterium** – Summanden müssen Nullfolge sein
- **geometrische Reihe** – Σ qᵏ, Wert 1/(1 − q) für |q| < 1
- **harmonische Reihe** – Σ 1/k, divergent
- **Teleskopsumme** – Terme heben sich paarweise weg (R-5)
- **Definitionsmenge, Wertemenge, Bild** – erlaubte x, Zielmenge, wirklich angenommene Werte
- **Umkehrfunktion** f⁻¹ – macht f rückgängig, Spiegelung an y = x
- **Graph, Vertikaltest** – Punkte (x, f(x)); höchstens ein Punkt über jedem x
- **Verkettung** f ∘ g – zuerst g, dann f
- **beschränkt, monoton** – Werte bleiben unter/über einer Schranke; Werte steigen/fallen
- **Grenzwert, einseitiger Grenzwert, uneigentlicher Grenzwert** – lim_{x→x̂}, von rechts/links, ± ∞
- **stetig** – lim_{x→x̂} f(x) = f(x̂)
- **Sprungstelle, Polstelle, Oszillationsstelle** – die drei Unstetigkeitstypen

**Beispiel 1: Konvergente und divergente Reihen**
- **Σₖ₌₀^∞ 1/2ᵏ** = 1 + ½ + ¼ + … Geometrisch mit q = ½, Start k = 0 ⇒ erstes Glied 1.
  - Teilsummen: s₀ = 1, s₁ = 1,5, s₂ = 1,75, s₃ = 1,875, s₄ = 1,9375. Formel sₙ = 2 − 1/2ⁿ.
  - 1/2ⁿ → 0 ⇒ sₙ → **2**. Konvergent, Summe 2 (= 1/(1 − ½)).
- **Σₖ₌₀^∞ 2ᵏ** = 1 + 2 + 4 + 8 + …
  - Teilsummen: 1, 3, 7, 15, 31, also sₙ = 2ⁿ⁺¹ − 1 → ∞. **Divergent** (q = 2, |q| ≥ 1).
- **Harmonische Reihe Σₖ₌₁^∞ 1/k** = 1 + ½ + ⅓ + ¼ + …

  - Gruppieren: ½ + (⅓ + ¼) + (⅕ + ⅙ + ⅐ + ⅛) + … Jede Klammer ist ≥ ½ (⅓ + ¼ ≥ ¼ + ¼ = ½), und es gibt unendlich
    viele Klammern ⇒ **divergent** (→ ∞), obwohl 1/k → 0.

**Beispiel 2: Notwendiges Kriterium**
- **Σ 2ᵏ:** 2ᵏ → ∞, also **keine** Nullfolge ⇒ Reihe **divergent**. Fertig.
- **Σ 1/k:** 1/k → 0 ⇒ Kriterium erfüllt, aber das sagt **nichts**. Tatsächlich divergent (Beispiel 1).
- **Σ 1/k²:** 1/k² → 0 ⇒ Kriterium erfüllt, sagt wieder **nichts**. Tatsächlich konvergent (Summe π²/6 ≈ 1,645).
- Lehre: Das Kriterium kann nur „divergent“ beweisen, nie „konvergent“.

**Beispiel 3: Σₖ₌₁^∞ 6/k²**

### Aufgabe FU-2 (Hausaufgabe): größter Definitionsbereich D und Bild
**Rezept:** Nenner ≠ 0, unter der Wurzel ≥ 0. Dann überlegen, welche Werte wirklich herauskommen.

- **a) x ↦ (x + 1)/(x − x):** ⚠️ **Wahrscheinlich Tippfehler auf der Folie.** x − x = 0 für **jedes** x, der Nenner
  ist also immer 0. ⇒ **D = ∅** (leere Menge), Bild ∅. Was gemeint war, ist nicht eindeutig (vielleicht
  (x + 1)/(x − 1)? Dann wäre D = ℝ \ {1} und das Bild ℝ \ {1}, weil (x + 1)/(x − 1) = 1 + 2/(x − 1) nie 1 wird).
  In der nächsten Vorlesung nachfragen.
- **b) x ↦ 1/(x⁴ − 2x² + 1):**
  1. Nenner erkennen: x⁴ − 2x² + 1 = (x² − 1)² (binomische Formel mit x² statt x).
  2. Nenner = 0 ⇔ x² = 1 ⇔ x = 1 oder x = −1 ⇒ **D = ℝ \ {−1, 1}**.
  3. Bild: (x² − 1)² ist ein Quadrat, auf D also **echt positiv**, und es nimmt jeden positiven Wert an (bei x = 0
     ist es 1, für x → ±∞ wird es riesig, nahe x = 1 winzig). Der Kehrwert nimmt also auch jeden positiven Wert an
     ⇒ **Bild (0, ∞)**. Zahlen: f(0) = 1, f(2) = 1/9, f(1,1) ≈ 22,7.
- **c) x ↦ (x² + 3x + 2)/(x² + x − 2):**
  1. Faktorisieren: Zähler (x + 1)(x + 2), Nenner (x + 2)(x − 1). Probe: x = −2 ist bei beiden Nullstelle.
  2. Nenner = 0 bei x = −2 und x = 1 ⇒ **D = ℝ \ {−2, 1}**.
  3. Kürzen (für x ≠ −2): f(x) = (x + 1)/(x − 1) = 1 + 2/(x − 1).
  4. 2/(x − 1) nimmt jeden Wert außer 0 an ⇒ (x + 1)/(x − 1) jeden Wert außer **1**.
  5. Aber x = −2 ist verboten: dort hätte die gekürzte Form den Wert (−1)/(−3) = **1/3**. Wird 1/3 woanders
     angenommen? 1 + 2/(x − 1) = 1/3 ⇒ 2/(x − 1) = −2/3 ⇒ x − 1 = −3 ⇒ x = −2. Nur dort ⇒ 1/3 fehlt.
  6. **Bild = ℝ \ {1/3, 1}**. Zahlen: f(0) = −1, f(3) = 2, f(−3) = 0,5.
- **d) x ↦ √(x² − 2x − 1):**
  1. Unter der Wurzel ≥ 0: x² − 2x − 1 ≥ 0. Quadratisch ergänzen: (x − 1)² − 2 ≥ 0 ⇔ (x − 1)² ≥ 2
     ⇔ |x − 1| ≥ √2.
  2. **D = (−∞, 1 − √2] ∪ [1 + √2, ∞)** ≈ (−∞; −0,414] ∪ [2,414; ∞).
  3. Bild: Am Rand ist der Wert √0 = 0, nach außen wächst er beliebig ⇒ **Bild [0, ∞)**. Zahlen: f(3) = √2,
     f(−1) = √2.

### Aufgabe FU-3 (Hausaufgabe): Welche Funktion hat eine Umkehrfunktion?
- **a) f: ℝ \ {0} → ℝ \ {0}, x ↦ 1/x³**
  1. Injektiv: x³ ist streng monoton, also wird jeder Wert 1/x³ nur einmal getroffen.
  2. Surjektiv: Jedes y ≠ 0 kommt heraus, nämlich bei x = 1/∛y (auch für negative y: ∛(−8) = −2).
  3. ⇒ bijektiv, **Umkehrfunktion existiert**. Auflösen: y = 1/x³ ⇒ x³ = 1/y ⇒ x = 1/∛y.
  4. **f⁻¹: ℝ \ {0} → ℝ \ {0}, x ↦ 1/∛x** (= x^(−1/3), für negative x als ∛ mit Vorzeichen gemeint).
  5. Probe: f(2) = 1/8, f⁻¹(1/8) = 1/∛(1/8) = 1/(1/2) = 2 ✓. f(−1/2) = −8, f⁻¹(−8) = 1/(−2) = −1/2 ✓.

### Aufgabe FU-8 (Hausaufgabe): Umkehrfunktion einer zusammengesetzten Funktion
f(x) = x² − 2x + 2 für x ≥ 1 und f(x) = 4x − 2x² − 1 für x < 1.
1. **Beide Teile quadratisch ergänzen:**
   - x ≥ 1: x² − 2x + 2 = (x − 1)² + 1. Für x ≥ 1 steigt das, Werte von 1 (bei x = 1) bis ∞ ⇒ Werte **[1, ∞)**.
   - x < 1: 4x − 2x² − 1 = −2(x² − 2x) − 1 = −2(x − 1)² + 1. Für x < 1 steigt das auch (nach links fällt es ab),
     Werte unter 1 bis −∞ ⇒ Werte **(−∞, 1)**.
2. **Bijektiv?** Beide Teile streng steigend, sie treffen sich bei x = 1 im Wert 1, und die Wertebereiche
   (−∞, 1) und [1, ∞) passen lückenlos zusammen ⇒ f ist streng monoton wachsend und trifft jedes y ∈ ℝ genau
   einmal ⇒ Umkehrfunktion existiert.
3. **Auflösen, Fall y ≥ 1** (kommt vom Teil x ≥ 1): y = (x − 1)² + 1 ⇒ (x − 1)² = y − 1 ⇒ x − 1 = +√(y − 1)
   (Plus, weil x ≥ 1) ⇒ x = 1 + √(y − 1).
4. **Auflösen, Fall y < 1** (kommt vom Teil x < 1): y = 1 − 2(x − 1)² ⇒ (x − 1)² = (1 − y)/2 ⇒
   x − 1 = −√((1 − y)/2) (Minus, weil x < 1) ⇒ x = 1 − √((1 − y)/2).
5. **Ergebnis:** f⁻¹(x) = **1 + √(x − 1) für x ≥ 1** und **1 − √((1 − x)/2) für x < 1**.
6. **Nachweis**, dass es wirklich die Umkehrfunktion ist (beide Richtungen):
   - f⁻¹(f(x)) = x: Für x ≥ 1 ist f(x) = (x − 1)² + 1 ≥ 1, also f⁻¹(f(x)) = 1 + √((x − 1)²) = 1 + |x − 1| =
     1 + (x − 1) = x ✓. Für x < 1 ist f(x) = 1 − 2(x − 1)² < 1, also f⁻¹(f(x)) = 1 − √((x − 1)²) = 1 − |x − 1| =
     1 − (1 − x) = x ✓.
   - f(f⁻¹(y)) = y: Für y ≥ 1 ist f⁻¹(y) = 1 + √(y − 1) ≥ 1, also f(…) = (√(y − 1))² + 1 = y ✓. Für y < 1 ist
     f⁻¹(y) = 1 − √((1 − y)/2) < 1, also f(…) = 1 − 2 · (1 − y)/2 = 1 − (1 − y) = y ✓.
7. **Zahlenprobe:** f(3) = 5, f⁻¹(5) = 1 + √4 = 3 ✓. f(−1) = −4 − 2 − 1 = −7, f⁻¹(−7) = 1 − √4 = −1 ✓.

### Funktionen: injektiv, surjektiv, bijektiv (Rückfrage)
- **injektiv:** jeder Wert rechts wird **höchstens einmal** getroffen (x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂)).
- **surjektiv:** jeder Wert der Zielmenge wird **mindestens einmal** getroffen.
- **bijektiv:** beides ⇒ **genau einmal** ⇒ Umkehrfunktion existiert.
- Schnelltest: waagrechte Linien – höchstens/mindestens/genau ein Schnittpunkt.
- Hängt von den Mengen ab: x² ist ℝ→ℝ weder noch; ℝ→[0,∞) surjektiv; [0,∞)→ℝ injektiv; [0,∞)→[0,∞) bijektiv (f⁻¹ = √).

### Beispiel Umkehrfunktion (Folie 62): f: [2, ∞) → ℝ, x ↦ x² − 4x + 1
- Warum [2, ∞)? Quadratische Ergänzung: x² − 4x + 1 = (x − 2)² − 3 ⇒ Scheitel bei x = 2, f(2) = −3. Rechts vom
  Scheitel streng steigend ⇒ injektiv.
- Auflösen: y = (x − 2)² − 3 ⇒ y + 3 = (x − 2)² ⇒ x − 2 = +√(y + 3) (nur +, weil x ≥ 2) ⇒ **f⁻¹(x) = 2 + √(x + 3)**.
- Falle: Werte sind nur ≥ −3 ⇒ sauber f: [2,∞) → [−3,∞) bijektiv, f⁻¹: [−3,∞) → [2,∞).
- Probe: f(5) = 6, f⁻¹(6) = 2 + 3 = 5 ✓
- Rezept: injektiv? (sonst einschränken, bei Parabeln ab Scheitel) → Wertebereich → y = f(x) nach x auflösen →
  passendes Vorzeichen → Probe.

### Rechenbeispiele Beschränktheit und Monotonie (Folie 73)

### Beispiele: Grenzwerte von Funktionen (Folie 75)

### Was „konvergent“ bei Reihen heißt – und wozu Kriterien (Rückfragen aus der Vorlesung)
- **Konvergenz einer Reihe** = die **Partialsummen** Sₙ = a₁ + … + aₙ haben für n → ∞ einen **endlichen Grenzwert**.
  (Bei einer Folge: die einzelnen Glieder aₙ haben einen Grenzwert.)
- **„Konvergent für alle x“ (R-4b):** x ist eine **feste** Zahl, die man vorher wählt; **k** läuft gegen ∞. Für jedes
  feste x haben die Partialsummen einen endlichen Grenzwert (je nach x ein anderer). Bei großem x werden die Glieder
  erst riesig (x = 10: Glied k = 10 ≈ 2,76 Mio.), dann schrumpfen sie, weil k! schneller wächst als k³·xᵏ
  (k = 40 ≈ 0,0008). Für Konvergenz zählt nur das Ende. Verwandt: Σ xᵏ/k! = eˣ.
- **Wozu Kriterien?** Sie beantworten nur „Gibt es einen Grenzwert – ja/nein?“, ohne ihn auszurechnen. Den Wert kann
  man meist gar nicht berechnen (Σ 1/k⁵ hat keine einfache Formel). Daher R-4: „Ein Grenzwert braucht nicht angegeben
  zu werden.“ Ausrechnen nur in Sonderfällen (geometrische Reihe: erstes Glied/(1−q)).

### Folge vs. Reihe: „höchste Potenz“
- **Folge:** höchste Potenz entscheidet, wohin **ein** Glied geht: (4n²+3)/(3n²−n) → 4/3.
- **Reihe:** Glieder → 0 reicht **nicht**: Folge 1/k → 0, aber Reihe Σ 1/k **divergiert** (harmonische Reihe).
- Bei Brüchen aus Potenzen von k: **Abstand = Grad Nenner − Grad Zähler**
  - Abstand ≤ 0 → Glieder ↛ 0 → **divergent** (z. B. Σ 3k²/(k²+1), Glieder → 3)
  - Abstand = 1 → wie 1/k → **divergent** (z. B. Σ k/(k²+5))
  - Abstand > 1 → wie 1/k², 1/k³ … → **konvergent** (z. B. Σ (k+1)/(k³+2): Abstand 2; Σ 1/(2k⁵): Abstand 5)
  - Dahinter steckt das **Vergleichskriterium** mit Σ 1/kᵖ. Gilt nur für Brüche aus Potenzen; bei k! oder xᵏ →
    Quotientenkriterium.
- Merksatz: *Folge → wohin geht ein Glied? Reihe → Potenzabstand muss größer als 1 sein.*

### Übersicht Konvergenzkriterien (Ergänzung; auf den Folien stehen nur notwendiges Kriterium und geometrische Reihe)
| Kriterium | wann | Regel |
|---|---|---|
| Divergenzkriterium | immer zuerst | Summanden ↛ 0 ⇒ divergent (→ 0: noch keine Aussage) |
| geometrische Reihe | qᵏ | konvergent ⇔ \|q\| < 1, Wert = erstes Glied/(1−q) |
| Σ 1/kᵖ („Riemann“, Tafel) | k unten, fester Exponent | konvergent ⇔ p > 1 |
| Quotientenkriterium | k!, xᵏ, aᵏ | L = lim \|aₖ₊₁/aₖ\|: < 1 konv., > 1 div., = 1 keine Aussage |
| Wurzelkriterium | alles „hoch k“ | L = lim ᵏ√\|aₖ\|, gleiche Regel |
| Leibniz | (−1)ᵏ, Vorzeichen wechseln | \|aₖ\| monoton fallend → 0 ⇒ konvergent |
| Majorante/Minorante | ähnlich zu bekannter Reihe | kleiner als konvergente ⇒ konv.; größer als divergente ⇒ div. |

Reihenfolge: 1. Summanden → 0? 2. bekannte Form (qᵏ, 1/kᵖ)? 3. k!/„hoch k“ → Quotient/Wurzel. 4. Vorzeichenwechsel →
Leibniz. 5. sonst vergleichen.

Geschichte (kurz): Oresme (~1350) harmonische Reihe divergiert · Leibniz (~1713) alternierende Reihen · Euler (1734/35)
Σ 1/k² = π²/6 · d'Alembert (1768) Quotientenkriterium · Cauchy (1821, *Cours d'analyse*) strenge Konvergenz,
Wurzelkriterium · Riemann (1854 Umordnungssatz, 1859 ζ(p) = Σ 1/kᵖ).

### Periodenzahlen als geometrische Reihe (Tafel, Aufgabe R-3)
Tafelformel: endliche Summe v₀ · (1 − qⁿ⁺¹)/(1 − q); für n → ∞ und |q| < 1 gilt qⁿ⁺¹ → 0, also **v₀ / (1 − q)**
(v₀ = erstes Glied). Trick: Periodenlänge 1 → q = 1/10, Länge 2 → q = 1/100.

- **a) 0,3̄** = 3/10 + 3/100 + … = Σ_{k=1} 3·(1/10)ᵏ → (3/10)/(9/10) = **1/3**
- **b) 0,1̄2̄** = 12/100 + 12/10 000 + … = Σ_{k=1} 12·(1/100)ᵏ → (12/100)/(99/100) = 12/99 = **4/33**
- **c) 4,312̄** (Periode nur 2) = 4,31 + (0,002 + 0,0002 + …) = 431/100 + (2/1000)/(9/10) = 431/100 + 2/900 =
  **3881/900** (Probe 4,31222… ✓). Die Folie (Aufgabe R-3) bestätigt: Periode nur „2“.

### Anwendung: Sparplan und Rentenrechnung (Tafel + Folie)
**Einmalige Zahlung** r im Jahr 0, Zinssatz i:
- Jahr 1: r + i·r = (1+i)·r · Jahr 2: R + i·R = (1+i)·R = (1+i)²·r · … · Jahr n: **(1+i)ⁿ·r** (Zinseszins).

**Jedes Jahr r eingezahlt** (Sparplan, n Einzahlungen): Endwert = [im Jahr 0 eingezahlt] + [im Jahr 1 eingezahlt] + …
Jede Einzahlung wird einzeln verzinst; die letzte 0 Jahre, die vorletzte 1 Jahr, …, die erste n−1 Jahre:

> Eₙ = r + r(1+i) + r(1+i)² + … + r(1+i)ⁿ⁻¹ = Σ_{k=0}^{n−1} r(1+i)ᵏ = r · Σ_{k=0}^{n−1} (1+i)ᵏ

Das ist eine **endliche geometrische Reihe mit q = 1+i** (r als Faktor vor die Summe gezogen).
Summenformel: Σ_{k=0}^{n−1} qᵏ = (qⁿ − 1)/(q − 1) = (1 − qⁿ)/(1 − q) (Zähler und Nenner mal −1).
Einsetzen q = 1+i, Nenner (1+i) − 1 = i:

> **Eₙ = r · ((1+i)ⁿ − 1) / i**   (Folie: „Summenformel der endlichen geometrischen Reihe mit q = 1+i“)

Rechenbeispiel (Routine): r = 100 €, i = 5 % = 0,05, n = 3 → 100 · (1,05³ − 1)/0,05 = 100 · 0,157625/0,05 =
**315,25 €**. Probe: 100·1,05² + 100·1,05 + 100 = 110,25 + 105 + 100 = 315,25 ✓.

Achtung: Hier ist q = 1+i **größer als 1** → nur die **endliche** Summenformel gilt; die unendliche Formel v₀/(1−q)
nur bei |q| < 1. i immer als Dezimalzahl einsetzen (5 % = 0,05).


### Beispiel Stetigkeit (Folie 79): c so bestimmen, dass f stetig ist

f(x) = (x² + 2x − 3)/(x² + x − 2) für x ≠ 1, f(1) = c.

- **Idee:** Stetig heißt, dass der Graph keine Lücke und keinen Sprung hat. Der Wert c muss also genau dort liegen, wo der Graph bei x = 1 „hinläuft“: c = lim x→1 f(x).
- **Einsetzen:** (1 + 2 − 3)/(1 + 1 − 2) = 0/0, also umformen.
- **Faktorisieren:** x² + 2x − 3 = (x + 3)(x − 1) und x² + x − 2 = (x + 2)(x − 1). Probe: x = 1 ist bei beiden eine Nullstelle.
- **Kürzen:** (x + 3)/(x + 2), dann x = 1 einsetzen ergibt 4/3.
- **Ergebnis:** **c = 4/3**. Jedes andere c ergibt eine Lücke mit einem „falschen Punkt“ daneben, dann ist f bei 1 unstetig.

### Beispiele Verkettung von Funktionen (Folie 68)

**Regel:** (g ∘ f)(x) = g(f(x)), gelesen „g nach f“. **Zuerst f, dann g.** Wichtig: Was f ausgibt, muss im Definitionsbereich von g liegen.

**a)** f: ℝ → ℝ, x ↦ sin(x) und g: [−2, 2] → ℝ, x ↦ 1 − x²
- f gibt Werte von −1 bis 1 aus. Die liegen alle in [−2, 2], die Verkettung klappt also für alle x.
- h(x) = g(sin x) = **1 − sin²(x)**, das ist dasselbe wie cos²(x). h: ℝ → ℝ.

**b)** g: (0, 1) → ℝ, x ↦ 1/(x² − x) und f: ℝ → ℝ, x ↦ 1/(1 + x²)
- f gibt Werte in (0, 1] aus. Problem: f(0) = 1, aber 1 liegt **nicht** in (0, 1), weil das Intervall offen ist. Für x = 0 geht die Verkettung also nicht.
- h(x) = 1 / (f² − f) mit f = 1/(1 + x²). Es gilt f − 1 = −x²/(1 + x²), also f · (f − 1) = −x²/(1 + x²)².
- **h(x) = −(1 + x²)² / x²**, Definitionsbereich ℝ \ {0}.
- Probe x = 1: f(1) = ½, g(½) = 1/(¼ − ½) = −4. Formel: −(2)²/1 = −4 ✓

### Aufgabe FU-6 (Folie 85): Richtig oder falsch? f: (a, b) → ℝ

**Taktik:** Für „falsch“ reicht **ein Gegenbeispiel**.

- **a) falsch.** Links- und rechtsseitiger Grenzwert stimmen überein, aber f(x̂) kann trotzdem woanders liegen. Gegenbeispiel: f(x) = 0 für x ≠ 0 und f(0) = 1. Beide Grenzwerte sind 0, der Punkt liegt bei 1, also ein Sprung.
- **b) richtig.** Das ist genau die Definition von stetig: Der Grenzwert existiert **und** ist gleich f(x̂).
- **c) falsch.** Das Intervall ist offen, deshalb kann f am Rand nach ∞ laufen. Gegenbeispiel: f(x) = 1/x auf (0, 1).
- **d) falsch.** Eine Nullstelle heißt nicht, dass das Vorzeichen wechselt. Gegenbeispiel: f(x) = x² auf (−1, 1) hat die Nullstelle 0, ist aber nie negativ.
- **e) falsch.** „Monoton“ erlaubt auch konstant, z. B. f(x) = 5: Der Wert 5 wird überall angenommen. Erst mit **streng** monoton wäre es richtig (dann ist f injektiv).
