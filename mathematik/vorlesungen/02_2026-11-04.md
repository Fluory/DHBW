### Teil 2: Reihen – „Folgen aufaddieren“

**Was ist eine Reihe?** Man nimmt eine Folge a₁, a₂, a₃, … und addiert die Glieder nacheinander auf. Die
Zwischenergebnisse heißen **Partialsummen**:

- s₁ = a₁
- s₂ = a₁ + a₂
- s₃ = a₁ + a₂ + a₃
- allgemein sₙ = a₁ + a₂ + … + aₙ = Σₖ₌₁ⁿ aₖ

Die **Reihe** Σₖ₌₁^∞ aₖ ist die **Folge dieser Partialsummen** (sₙ). Konvergiert (sₙ) gegen eine Zahl s, sagt man
„die Reihe konvergiert, ihr **Wert** ist s“ und schreibt Σₖ₌₁^∞ aₖ = s. Sonst ist die Reihe divergent.

**Rechenbeispiel (Kuchen):** Du isst einen halben Kuchen, dann die Hälfte vom Rest, dann wieder die Hälfte vom
Rest …: ½ + ¼ + ⅛ + 1/16 + …
- s₁ = 0,5 · s₂ = 0,75 · s₃ = 0,875 · s₄ = 0,9375 · s₅ = 0,96875
- Die Partialsummen kommen der 1 beliebig nahe → Σₖ₌₁^∞ (½)ᵏ = **1**. Unendlich viele Summanden, aber eine
  endliche Summe!

⚠️ Zwei Folgen nicht verwechseln: die Folge der **Summanden** aₖ (hier ½, ¼, ⅛ … → 0) und die Folge der
**Partialsummen** sₙ (hier 0,5; 0,75; … → 1). Der Wert der Reihe ist der Grenzwert der **Partialsummen**.

#### Die geometrische Reihe (wichtigste Reihe überhaupt)
Σₖ₌₀^∞ qᵏ = 1 + q + q² + q³ + … = **1/(1 − q)**, falls |q| < 1. Für |q| ≥ 1 divergiert sie.

Herleitung aus Termin 1: Endliche Summe sₙ = 1 + q + … + qⁿ = (1 − qⁿ⁺¹)/(1 − q) (das ist die Summenformel der
geometrischen Folge mit a₁ = 1). Für |q| < 1 gilt qⁿ⁺¹ → 0, also sₙ → 1/(1 − q).

Mit Startwert a (erstes Glied) und Faktor q: a + aq + aq² + … = **a/(1 − q)**.

Rechenbeispiele:
- q = ½, ab k = 0: 1 + ½ + ¼ + … = 1/(1 − ½) = **2**
- q = ⅓: 1 + ⅓ + 1/9 + … = 1/(1 − ⅓) = **3/2**
- q = −½: 1 − ½ + ¼ − ⅛ + … = 1/(1 + ½) = **2/3**
- Start bei k = 1: Σₖ₌₁^∞ (½)ᵏ = (erstes Glied ½)/(1 − ½) = **1** (der Kuchen von oben)
- 0,999… = 9/10 + 9/100 + … = (9/10)/(1 − 1/10) = **1**
- q = 2: 1 + 2 + 4 + … → ∞ (divergent, weil |q| ≥ 1)

⚠️ Typischer Fehler: Startindex übersehen. Die Formel 1/(1 − q) gilt für den Start bei k = 0 (erstes Glied = 1).
Startet die Summe woanders, rechnet man **erstes Glied / (1 − q)**.

#### Notwendige Bedingung: Summanden müssen gegen 0 gehen
Wenn Σ aₖ konvergiert, dann ist (aₖ) eine **Nullfolge**. Umgekehrt (Kontraposition, das „Divergenzkriterium“):
Geht aₖ **nicht** gegen 0, divergiert die Reihe sicher.
- Beispiel: Σ k/(k + 1): aₖ → 1 ≠ 0 → divergent. Man addiert immer fast 1 dazu.
- Beispiel: Σ (−1)ᵏ: aₖ springt zwischen −1 und 1 → divergent; Partialsummen −1, 0, −1, 0, …

#### Die harmonische Reihe – die große Falle
Σₖ₌₁^∞ 1/k = 1 + ½ + ⅓ + ¼ + … **divergiert** (gegen +∞), obwohl 1/k → 0.
- s₁₀ ≈ 2,93; s₁₀₀ ≈ 5,19; s₁ ₀₀₀ ₀₀₀ ≈ 14,4 – wächst sehr langsam, aber ohne Grenze.
- Grund (Gruppieren): ½ + (⅓ + ¼) + (⅕ + … + ⅛) + … – jede Klammer ist ≥ ½, und es gibt unendlich viele davon.
- **Merksatz:** aₖ → 0 ist **notwendig, aber nicht hinreichend**.
- Zum Vergleich: Σ 1/k² konvergiert (Wert π²/6 ≈ 1,645). Allgemein Σ 1/kᵅ konvergiert genau für α > 1.

#### Teleskopsumme (Beispiel, wie man einen Reihenwert exakt bekommt)
Σₖ₌₁^∞ 1/(k(k + 1)): Trick 1/(k(k + 1)) = 1/k − 1/(k + 1). Dann heben sich fast alle Terme weg:
sₙ = (1 − ½) + (½ − ⅓) + … + (1/n − 1/(n + 1)) = 1 − 1/(n + 1) → **1**.
Nachrechnen: s₄ = 1/2 + 1/6 + 1/12 + 1/20 = 0,8 = 1 − 1/5. ✓

#### Konvergenzkriterien (wahrscheinlich, aber nicht sicher in der Vorlesung)
- **Quotientenkriterium:** Berechne q = lim |aₖ₊₁/aₖ|. q < 1 → konvergent · q > 1 → divergent · q = 1 → keine
  Aussage. Beispiel Σ 1/k!: aₖ₊₁/aₖ = 1/(k + 1) → 0 < 1 → konvergent (Wert e − 1 ab k = 1, bzw. e ab k = 0).
  Beispiel Σ k/2ᵏ: aₖ₊₁/aₖ = (k + 1)/(2k) → ½ < 1 → konvergent.
- **Leibniz-Kriterium (alternierende Reihen):** Σ (−1)ᵏ aₖ konvergiert, wenn aₖ eine **monoton fallende Nullfolge**
  ist. Beispiel 1 − ½ + ⅓ − ¼ + … konvergiert (gegen ln 2 ≈ 0,693), obwohl die harmonische Reihe divergiert.
  s₅ = 1 − 0,5 + 0,333 − 0,25 + 0,2 ≈ 0,783.
- **Vergleichs-/Majorantenkriterium:** Ist 0 ≤ aₖ ≤ bₖ und Σ bₖ konvergiert, dann konvergiert auch Σ aₖ.

#### Anwendung Wirtschaft (passt zu WI, evtl. Beispiel in der Vorlesung)
- **Zinseszins** (geometrische Folge): 1000 € zu 5 % nach 10 Jahren: 1000 · 1,05¹⁰ ≈ **1628,89 €**.
- **Sparplan/Rente** (endliche geometrische Reihe): 10 Jahre lang je 100 € am Jahresende bei 5 %:
  100 · (1,05¹⁰ − 1)/0,05 ≈ **1257,79 €**.
- **Ewige Rente** (unendliche geometrische Reihe): Barwert von jährlich 100 € für immer bei 5 %:
  Σₖ₌₁^∞ 100/1,05ᵏ = 100/0,05 = **2000 €**.

### Teil 3 (nur falls Zeit): Einstieg Kapitel 2 – Reellwertige und stetige Funktionen
- **Funktion** f: D → ℝ ordnet jedem x aus dem Definitionsbereich D genau ein f(x) zu. Beispiel f(x) = 1/(x − 2):
  D = ℝ \ {2}.
- **Grenzwert einer Funktion** lim_{x→x₀} f(x): Man nimmt **jede** Folge xₙ → x₀ und schaut, wohin f(xₙ) geht – so
  wird das Folgenwissen wiederverwendet. Beispiel lim_{x→2} (x² − 4)/(x − 2) = lim (x + 2) = **4** (kürzen!).
- **Stetig** in x₀ heißt: lim_{x→x₀} f(x) = f(x₀) – anschaulich „Graph ohne Absetzen zeichnen“. Polynome, eˣ, sin,
  cos sind überall stetig; 1/x ist auf seinem Definitionsbereich stetig. Die Vorzeichenfunktion springt bei 0 →
  dort unstetig.

## Wichtige Formeln / Rechenregeln (kompakt)
- Partialsumme sₙ = Σₖ₌₁ⁿ aₖ; Reihenwert = lim sₙ
- Geometrische Reihe: Σₖ₌₀^∞ qᵏ = 1/(1 − q) für |q| < 1; allgemein erstes Glied/(1 − q)
- Endliche geometrische Summe: Σₖ₌₀ⁿ qᵏ = (1 − qⁿ⁺¹)/(1 − q)
- Divergenzkriterium: aₖ ↛ 0 ⇒ Σ aₖ divergiert
- Harmonische Reihe Σ 1/k divergiert; Σ 1/k² konvergiert
- Reihen darf man gliedweise addieren und mit Konstanten multiplizieren, wenn beide konvergieren:
  Σ (c·aₖ + bₖ) = c·Σ aₖ + Σ bₖ
- Quotientenkriterium: lim |aₖ₊₁/aₖ| < 1 ⇒ konvergent, > 1 ⇒ divergent, = 1 ⇒ keine Aussage
- Leibniz: (−1)ᵏ · (monoton fallende Nullfolge) ⇒ konvergent
- Wachstums-Rangfolge für Grenzwerte: ln n ≪ √n ≪ n ≪ n² ≪ … ≪ 2ⁿ ≪ eⁿ ≪ n!

## Typische Fehler
- Folge der Summanden mit Folge der Partialsummen verwechseln („aₖ → 0, also Reihe = 0“ – falsch).
- Aus aₖ → 0 auf Konvergenz der Reihe schließen (harmonische Reihe!).
- Geometrische Reihe bei |q| ≥ 1 benutzen (z. B. 1/(1 − 2) = −1 für 1 + 2 + 4 + … – Unsinn).
- Startindex vergessen: Σₖ₌₁^∞ (½)ᵏ = 1, nicht 2.
- Beim Quotientenkriterium aus „= 1“ etwas folgern.

## Wichtige Begriffe
- **Reihe** – Folge der Partialsummen einer Folge, geschrieben Σ aₖ
- **Partialsumme** sₙ – Summe der ersten n Glieder
- **Wert einer Reihe** – Grenzwert der Partialsummen (falls vorhanden)
- **geometrische Reihe** – Σ qᵏ, Wert 1/(1 − q) für |q| < 1
- **harmonische Reihe** – Σ 1/k, divergent
- **Teleskopsumme** – Terme heben sich paarweise weg
- **Divergenzkriterium / notwendige Bedingung** – Summanden müssen Nullfolge sein
- **Quotientenkriterium, Leibniz-Kriterium, Majorantenkriterium** – Tests für Konvergenz
- **Stetigkeit** (Ausblick) – lim_{x→x₀} f(x) = f(x₀)

### Aufgabe R-4: Welche Reihen sind konvergent? (Folie, Kriterium wählen, kein Grenzwert nötig)

### Periodenzahlen als geometrische Reihe (Tafel)
Tafelformel: endliche Summe v₀ · (1 − qⁿ⁺¹)/(1 − q); für n → ∞ und |q| < 1 gilt qⁿ⁺¹ → 0, also **v₀ / (1 − q)**
(v₀ = erstes Glied). Trick: Periodenlänge 1 → q = 1/10, Länge 2 → q = 1/100.

- **a) 0,3̄** = 3/10 + 3/100 + … = Σ_{k=1} 3·(1/10)ᵏ → (3/10)/(9/10) = **1/3**
- **b) 0,1̄2̄** = 12/100 + 12/10 000 + … = Σ_{k=1} 12·(1/100)ᵏ → (12/100)/(99/100) = 12/99 = **4/33**
- **c) 4,312̄** (Periode nur 2) = 4,31 + (0,002 + 0,0002 + …) = 431/100 + (2/1000)/(9/10) = 431/100 + 2/900 =
  **3881/900** (Probe 4,31222… ✓). Falls Periode „12“: 4,3121212… = 43/10 + 12/990 = **1423/330**.

### Anwendung: Sparplan und Rentenrechnung (Tafel + Folie)
**Einmalige Zahlung** r im Jahr 0, Zinssatz i:
- Jahr 1: r + i·r = (1+i)·r · Jahr 2: R + i·R = (1+i)·R = (1+i)²·r · … · Jahr n: **(1+i)ⁿ·r** (Zinseszins).

**Jedes Jahr r eingezahlt** (Sparplan, n Einzahlungen): Endwert = [im Jahr 0 eingezahlt] + [im Jahr 1 eingezahlt] + …
Jede Einzahlung wird einzeln verzinst; die letzte 0 Jahre, die vorletzte 1 Jahr, …, die erste n−1 Jahre:

> Eₙ = r + r(1+i) + r(1+i)² + … + r(1+i)ⁿ⁻¹ = Σ_{k=0}^{n−1} r(1+i)ᵏ = r · Σ_{k=0}^{n−1} (1+i)ᵏ

Das ist eine **endliche geometrische Reihe mit q = 1+i** (r als Faktor vor die Summe gezogen).
Summenformel: Σ_{k=0}^{n−1} qᵏ = (qⁿ − 1)/(q − 1) = (1 − qⁿ)/(1 − q) (Zähler und Nenner mal −1).
Einsetzen q = 1+i, Nenner (1+i) − 1 = i:

> **Eₙ = r · ((1+i)ⁿ − 1) / i**   (Folie: „Summenformel der endlichen geometrischen Reihe mit q = 1+i“)

Rechenbeispiel (Routine): r = 100 €, i = 5 % = 0,05, n = 3 → 100 · (1,05³ − 1)/0,05 = 100 · 0,157625/0,05 =
**315,25 €**. Probe: 100·1,05² + 100·1,05 + 100 = 110,25 + 105 + 100 = 315,25 ✓.

Achtung: Hier ist q = 1+i **größer als 1** → nur die **endliche** Summenformel gilt; die unendliche Formel v₀/(1−q)
nur bei |q| < 1. i immer als Dezimalzahl einsetzen (5 % = 0,05).
