### Rückblick Termin 3: Rechtsformen I

**Was ist das?** Gestern ging es um den Einstieg in Kapitel 3:

- Firma, Kaufmann nach HGB und Handelsregister

- Personengesellschaften: GbR/eGbR, OHG, KG und die stille Gesellschaft

**Das Wichtigste:** Personengesellschafter haften **unbeschränkt, unmittelbar und solidarisch**. Kommanditisten haften nur bis zu ihrer Haftsumme. Seit dem MoPeG (2024) wird der Gewinn nach den **Beteiligungsverhältnissen** verteilt und nicht mehr nach „4 % + Köpfe“.

**Achtung:** Ein Handelsregistereintrag kann deklaratorisch sein (er bestätigt nur, was schon gilt, z. B. beim Istkaufmann) oder konstitutiv (die Wirkung entsteht erst durch den Eintrag, z. B. bei der GmbH). Die Kapitelfolien fehlen noch, deshalb bleibt die Notiz vermutet.

### GmbH und UG

**Was ist das?** Die GmbH ist eine **juristische Person** mit mindestens **25.000 € Stammkapital**. Gehaftet wird nur mit dem Gesellschaftsvermögen. Die UG (haftungsbeschränkt) ist die „Mini-GmbH“, die schon ab 1 € gegründet werden kann. Beispiel: Zwei Studis gründen eine App-Firma als UG mit 500 €.

**Das Wichtigste:** Vor der Eintragung müssen auf jeden Anteil 25 % eingezahlt sein, insgesamt mindestens 12.500 €. Organe sind Geschäftsführer und Gesellschafterversammlung. Die Gesellschafterversammlung **darf dem Geschäftsführer Weisungen geben**.

**Achtung:** Die UG muss **25 % des Jahresüberschusses** in eine Rücklage stecken, bis 25.000 € erreicht sind. Das ist Musterklausur Aufgabe 2b. Eine Sachgründung ist bei der UG verboten.

### GmbH & Co. KG

**Was ist das?** Eine KG, deren Komplementär (der eigentlich voll haftende Gesellschafter) eine **GmbH** ist.

**Das Wichtigste:** Am Ende haftet **keine natürliche Person unbeschränkt**, und trotzdem gelten die flexibleren Regeln einer Personengesellschaft.

**Achtung:** In der Praxis verlangen Banken trotzdem persönliche Bürgschaften. Außerdem gibt es eine doppelte Verwaltung, nämlich zwei Gesellschaften mit zwei Buchhaltungen (Übung 19).

### AG und ihre Organe

**Was ist das?** Die AG ist eine Kapitalgesellschaft mit mindestens **50.000 € Grundkapital**, aufgeteilt in Aktien. Eine Aktie hat einen Nennbetrag von mindestens 1 €.

**Das Wichtigste:** Aktien dürfen nicht unter dem Nennwert ausgegeben werden. Was über dem Nennwert gezahlt wird, heißt **Agio**. Die drei Organe:

- **Vorstand:** leitet weisungsfrei, für höchstens 5 Jahre bestellt
- **Aufsichtsrat:** bestellt und überwacht den Vorstand
- **Hauptversammlung:** Aktionäre, beschließen unter anderem über die Gewinnverwendung

**Achtung:** Die Hauptversammlung kann dem Vorstand **keine Weisungen** geben. Das ist genau der Unterschied zur GmbH und kommt in der Musterklausur (2c).

### KGaA, SE, eG, Stiftung

**Was ist das?** Sonderformen:

- **KGaA:** mindestens ein voll haftender Komplementär plus Kommanditaktionäre
- **SE:** europäische AG mit mindestens 120.000 € Kapital
- **eG:** Genossenschaft mit mindestens 3 Mitgliedern, die ihre Mitglieder fördern soll (z. B. Volksbank)
- **Stiftung:** Vermögen für einen Zweck, ohne Eigentümer

**Das Wichtigste:** In der eG gilt **„ein Kopf, eine Stimme“**, unabhängig von der Höhe der Einlage.

**Achtung:** Die „fünf Gründer“ bei der KGaA im Skript sind veraltet. Heute reicht eine Person.

### Kapselung mit Properties (VL 5, Übung 4)

**Was ist das?** Eine Methode, die man wie ein Attribut benutzt. Im Hintergrund kann sie Werte prüfen:

```python
@property
def preis(self) -> float:
    return self._preis

@preis.setter
def preis(self, wert: float) -> None:
    if wert < 0:
        raise ValueError("Preis negativ")
    self._preis = wert
```

**Das Wichtigste:** `_preis` mit Unterstrich ist nur eine Konvention und kein Schutz. In `__init__` schreibst du `self.preis = preis`, dann prüft der Setter schon beim Anlegen. Eine Property ohne Setter ist schreibgeschützt.

**Achtung:** `kaffee.bestand = 100` auf eine Property ohne Setter gibt einen `AttributeError`. Und Properties ruft man **ohne Klammern** auf: `p.bruttopreis()` gibt einen `TypeError`.

### Hat-ein-Beziehung und @dataclass (VL 5, Übung 5)

**Was ist das?** Objekte können andere Objekte enthalten: Ein Warenkorb *hat* Produkte, eine Bestellung *hat einen* Kunden. `@dataclass` spart dabei Schreibarbeit:

```python
from dataclasses import dataclass

@dataclass
class Kunde:
    name: str
    email: str
```

**Das Wichtigste:** `@dataclass` erzeugt `__init__`, `__repr__` und `__eq__` automatisch. `==` vergleicht danach die **Werte**, `is` bleibt bei zwei Objekten `False`. In Übung 5 kommt als Warenkorb-Summe **36.45** heraus.

**Achtung:** Eine dataclass prüft die Werte nicht von selbst. Für „hat ein“ nimmst du **keine Vererbung**.

### Vererbung und super() (VL 6)

**Was ist das?** Eine Unterklasse übernimmt alles von der Oberklasse („ist ein“: ein Sparkonto *ist ein* Konto):

```python
class Sparkonto(Konto):
    def __init__(self, inhaber: str, kontostand: float, zins: float) -> None:
        super().__init__(inhaber, kontostand)
        self.zins = zins
```

**Das Wichtigste:** `super().__init__(...)` lässt die Oberklasse ihren Teil erledigen. `isinstance(s, Konto)` ist auch für ein Sparkonto `True`.

**Achtung:** Wenn du `super().__init__` vergisst, kommt der Fehler erst **später** als `AttributeError`, und `ty` meldet nichts.

### Überschreiben und @override (VL 6)

**Was ist das?** Die Unterklasse definiert eine Methode mit **gleichem Namen** neu und kann mit `super()` die alte Version mitbenutzen:

```python
@override
def monatskosten(self) -> float:
    return super().monatskosten() + 150 * self.teamgroesse
```

**Das Wichtigste:** Python sucht die Methode in der Reihenfolge der MRO (`__mro__`). Im Übungsbeispiel kommt für Tom 6700 heraus.

**Achtung:** Ein Tippfehler im Methodennamen legt still eine **neue** Methode an. `@override` macht das für `ty` sichtbar. Python kennt **Überschreiben, aber kein Überladen**.
