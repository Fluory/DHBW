### Machine-Learning-Grundbegriffe

**Was ist das?** Überwachtes und unüberwachtes Lernen unterscheiden sich so:

- **Überwachtes Lernen** sagt einen bekannten Zielwert vorher, das **Target**.
  - Ist das Target eine Zahl, heißt das **Regression**, z. B. ein Reisepreis.
  - Ist es eine Klasse, heißt es **Klassifikation**, z. B. „überlebt ja/nein“.
- **Unüberwachtes Lernen** hat kein Target und sucht selbst Muster, z. B. Kundengruppen.

**Das Wichtigste:** Zeilen sind Beobachtungen, Spalten sind **Features**. Die Daten teilt man in **Training und Test** (z. B. 80/20). **Parameter** lernt das Modell selbst, etwa die Verzweigungen im Entscheidungsbaum. **Hyperparameter** legst du vorher fest, etwa die maximale Tiefe oder k.

**Achtung:** Ist ein Modell auf den Trainingsdaten gut, muss es auf neuen Daten nicht gut sein. Das heißt **Overfitting**. Bei seltenen Klassen täuscht die Accuracy, schau dann auf Precision und Recall.

### k-Means: Kunden in Gruppen einteilen

**Was ist das?** Ein Verfahren, das Daten in **k Gruppen (Cluster)** einteilt:

1. k Zentren setzen.
2. Jeden Kunden dem nächsten Zentrum zuordnen.
3. Die Zentren auf den Mittelwert ihrer Gruppe verschieben.
4. Schritte 2 und 3 wiederholen, bis sich nichts mehr ändert.

Beispiel auf der Folie: k = 3, nach Umsatz pro Buchung und Anzahl der Buchungen.

**Achtung:** **k ist ein Hyperparameter**, du wählst es also selbst, es ist kein Ergebnis. Die Features vorher **skalieren**, sonst dominiert die Spalte mit den größten Zahlen.

### GenAI: LLM, RAG, Agent

**Was ist das?**

- **LLM:** sagt Token für Token das wahrscheinlichste nächste Wort vorher.
- **RAG:** sucht passende Dokumentstücke heraus und gibt sie im Prompt mit.
- **Agent:** arbeitet in mehreren Schritten und benutzt Werkzeuge, z. B. ein Spesen-Agent, der Belege prüft und weiterleitet.

**Achtung:** Bei RAG wird **nichts neu trainiert**. Das Wissen kommt nur über den Prompt dazu.

### Dataiku

**Was ist das?** Eine Plattform für Datenanalyse per Mausklick. Die Bausteine heißen **Projekt → Flow → Dataset → Recipe**. Der Ablauf:

1. Daten importieren.
2. Zusammenführen (Stack/Join) und aufbereiten (Prepare).
3. Aufteilen (Split).
4. Im **Lab** per **AutoML** trainieren.
5. Das beste Modell in den Flow **deployen**.
6. Neue Daten mit dem **Score**-Recipe bewerten.

**Achtung:** Nimm nur Features, die **zum Zeitpunkt der Vorhersage schon bekannt sind**. Sonst „schummelt“ das Modell mit Wissen aus der Zukunft. Das heißt **Data Leakage**.

So gehst du vor:

### Aufgabe 2: Titanic-Challenge auf Kaggle (90 min)

Das ist eine **Klassifikation** mit dem Target `Survived`. So gehst du vor:

1. Gute Features auswählen: Sex, Pclass, Age, Fare, FamilySize und der Titel aus dem Namen (Mr, Mrs, Miss …).
2. Im Lab per AutoML trainieren und das Modell deployen.
3. Das Testset scoren.
4. Abgeben als CSV mit den Spalten `PassengerId,Survived` (418 Zeilen, Werte 0/1).

**Achtung:** Zum Vergleich: „Alle sterben“ trifft etwa 62 %, „Frauen überleben“ schon etwa 77 %. Dein Modell sollte besser sein. Das Testset musst du **genauso aufbereiten** wie die Trainingsdaten.
