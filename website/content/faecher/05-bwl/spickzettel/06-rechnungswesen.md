| | extern | intern |

| Größen | Aufwand, Ertrag | Kosten, Leistung |

## Bilanz und GuV

**Bilanz** = Stichtag: Aktiva (Mittelverwendung) = Passiva (Mittelherkunft). **AV + UV = EK + FK.**

- Anlagevermögen: bleibt lange (Lizenzen, Gebäude, Maschinen, Beteiligungen).
- Umlaufvermögen: ändert sich ständig (Vorräte, Forderungen, Wertpapiere, flüssige Mittel).

Lücke füllen: AV 80.000 + UV 20.000 = 100.000 €; EK = 100.000 − FK 60.000 = **40.000 €**.

**GuV** = ganzes Jahr: Gewinn = Erträge (Wertzuwachs) − Aufwendungen (Werteverzehr). Gewinn erhöht das EK.
Erträge: Umsatzerlöse, Bestandserhöhungen, aktivierte Eigenleistungen, erhaltene Zinsen. Aufwand: Material, Personal, Abschreibungen, Bestandsminderungen, gezahlte Zinsen, Steuern.

## Kosten

Einzelkosten: direkt zurechenbar (Rohstoffe), stets variabel. Gemeinkosten: nicht direkt zurechenbar (Miete), meist fix.

**K = Kfix + kv · x**: K Gesamtkosten, Kfix Fixkosten, kv variable Stückkosten, x Menge.
Kfix 3.000 €, kv 1,50 €, x = 1.500 → K = **5.250 €**, je Stück 3,50 €.

## Zweipunktverfahren

1. Monat mit kleinster und größter **Menge** wählen.
2. kv = (K₂ − K₁) ÷ (x₂ − x₁)
3. Kfix = K₁ − kv · x₁
4. K = Kfix + kv · x

(500 | 49.000) und (800 | 70.000): kv = 21.000 ÷ 300 = **70 €**, Kfix = 49.000 − 35.000 = **14.000 €**, K(900) = **77.000 €**.

## Deckungsbeitrag

db = p − kv (p Preis, kv variable Stückkosten). DB = db · Menge. **Betriebsergebnis = Σ DB − Kfix.**

1. p und kv bestimmen (Gesamtwert ÷ Menge).
2. db, dann DB je Produkt.
3. DB addieren, Kfix abziehen.

A: 3.500 · (10 − 6) = 14.000 €. B: 5.000 · (16 − 12) = 20.000 €. 34.000 − 35.000 = **−1.000 €** (Verlust).

**Preisuntergrenze:** kurzfristig = kv; langfristig = kv + Kfix ÷ x.
kv 60 €, Kfix 115.000 €, x 7.000 → 60 € bzw. **76,43 €**.

## Nutzenschwelle (Break-even)

x = Kfix ÷ db. Umsatz an der Schwelle = x · p. Gewinn G = db · x − Kfix. Zielgewinn: x = (Kfix + Zielgewinn) ÷ db.

kv 45 €, Kfix 120.000 €, p 77 €: db = 32 € → x = **3.750 Stück**, Umsatz **288.750 €**.

## Make-or-buy

Kritische Menge x = Kfix ÷ (Fremdpreis − kv).

1. Eigen: Kfix + kv · x. Fremd: Fremdpreis · x.
2. Gleichsetzen, nach x auflösen.
3. Bedarf > x → selbst herstellen; Bedarf < x → kaufen.
4. Kontrolle mit echtem Bedarf.

Kfix 100.000 €, kv 20 €, Fremdpreis 30 €: x = **10.000 Stück**. Bedarf 20.000 → Eigenfertigung (500.000 € statt 600.000 €).

## Typische Fehler

- „Bank“ entscheidet nicht die Seite: Guthaben = Aktiva, Kredit = Passiva.
- Bilanz (Stichtag) und GuV (Jahr) verwechseln.
- Gezahlte Zinsen als Ertrag buchen.
- Zweipunktverfahren nach Kosten oder Nachbarmonaten wählen; kv gerundet weiterrechnen.
- Deckungsbeitrag für Gewinn halten.
- Nutzenschwelle durch den Preis teilen statt durch db.
- Make-or-buy durch Fremdpreis teilen statt durch (Fremdpreis − kv); Entscheidung nicht begründen.
- Gefragte Menge falsch lesen (15.000 statt 1.500); Kapazität 80 % als 100 % nehmen.
