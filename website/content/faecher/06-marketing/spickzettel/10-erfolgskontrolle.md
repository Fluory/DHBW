## Soll-Ist-Vergleich

**Soll:** Planwert. **Ist:** tatsächlicher Wert. **Abweichungsanalyse:** Gründe für die Differenz suchen.

Beispiel: Soll 50 €, Ist 68 € → Abweichung **18 €**, dann Ursache suchen.

## Absolute Kennzahlen (in €)

| Kennzahl | Formel |
|---|---|
| Umsatz | Preis · Absatzmenge |
| Kosten | fixe + variable Kosten |
| Gewinn oder Verlust | Umsatz − Kosten |
| Deckungsbeitrag | Umsatz − variable Kosten |
| Werbegewinn | werbebedingter Mehrumsatz − Werbekosten |

## Relative Kennzahlen (· 100, in %)

| Kennzahl | Formel | 4P-Bereich |
|---|---|---|
| Marktanteil | eigener Umsatz / Marktvolumen | allgemein |
| Reklamationsquote | Reklamationen / Aufträge | Produkt |
| Deckungsbeitrag in % | Deckungsbeitrag / Umsatz | Preis |
| Distributionsquote | Einkaufsorte mit Produkt / mögliche Einkaufsorte | Distribution |
| E-Commerce-Anteil | E-Commerce-Umsatz / Gesamtumsatz | Distribution |
| Werberendite | werbebedingter Mehrumsatz / Werbekosten | Kommunikation |
| Werbebudgetquote | Werbebudget / Umsatz | Kommunikation |
| Bekanntheitsgrad | Kenner / alle potenziellen Kunden | Kommunikation |
| Imagequote | Kunden mit geplantem Image / Kunden, die das Ziel kennen | Kommunikation |

**Tausenderpreis** = Kosten des Werbemediums · 1.000 / erreichte Personen (in €, ohne · 100). Bereich Kommunikation.
Beispiel: 125.000 · 1.000 / 6.500.000 = **19,23 €**.

**Mini-Beispiele:**

- Reklamationsquote: 30 / 3.000 · 100 = **1 %**
- Bekanntheitsgrad: 400 / 1.000 · 100 = **40 %**
- Distributionsquote: 300 / 500 · 100 = **60 %**

## Rechenweg: Kennzahlen aus einem Fall

1. Werte sortieren: Umsätze, Kosten, Werbezahlen, Reichweiten.
2. Absolute Kennzahlen zuerst: Gewinn, variable Kosten, Deckungsbeitrag, Werbegewinn.
3. Dann relative Kennzahlen: Zähler / Nenner · 100.
4. Mit Einheit (€ oder %) und auf 2 Stellen gerundet angeben.

**Beispiel:** Umsatz 400.000 €, Kosten 300.000 € (60 % variabel), Werbung 12.000 €, Mehrumsatz 30.000 €.

| Kennzahl | Rechnung | Ergebnis |
|---|---|---|
| Gewinn | 400.000 − 300.000 | 100.000 € |
| variable Kosten | 0,6 · 300.000 | 180.000 € |
| Deckungsbeitrag | 400.000 − 180.000 | 220.000 € |
| Werbegewinn | 30.000 − 12.000 | 18.000 € |
| DB in % | 220.000 / 400.000 · 100 | 55 % |
| Werberendite | 30.000 / 12.000 · 100 | 250 % |
| Werbebudgetquote | 12.000 / 400.000 · 100 | 3 % |

Werberendite 100 % → Werbung hat sich gerade so bezahlt (Werbegewinn 0 €).

## Typische Fehler

- Werbegewinn (Differenz, in €) und Werberendite (Quotient, in %) verwechseln.
- Beim Deckungsbeitrag alle Kosten statt nur der variablen abziehen.
- Variable Kosten nicht aus dem Anteil an den Gesamtkosten berechnen.
- Tausenderpreis mit · 100 rechnen oder in % angeben.
- Einheit oder Rundung auf 2 Stellen vergessen.
- Kennzahl dem falschen P zuordnen, z. B. Reklamationsquote zur Distribution statt zum Produkt.
