## Zu diesem Fach

### Worum es geht

Die Vorlesung heißt „Mathematik I – Analysis“. Sie beginnt mit **Folgen**: nummerierten Zahlenlisten und der Frage, wohin sie laufen. Daraus entstehen **Reihen**, unendliche Summen. Die geometrische Reihe ist die Grundlage der **Finanzmathematik** (Zinseszins, Sparplan, ewige Rente). Danach geht es um **Funktionen**: Umkehrfunktion, Monotonie, Grenzwerte und Stetigkeit.

Das Material sind die Foliensätze in Moodle („Analysis – Folgen“ vom 19.10. und „Analysis – Reihen + Funktionen“ vom 04.11.) mit den Aufgaben F-1 bis F-6, R-1 bis R-5 und FU-1 bis FU-8. Offizielle Lösungen gibt es nicht; die Lösungen hier sind selbst gerechnet.

## Mathe-Symbole vorlesen

Die Folien sind in Symbolen geschrieben. Ein Symbol, das du nicht vorlesen kannst, kannst du auch nicht verstehen. Diese Tabelle übersetzt jedes Zeichen, das auf den Folien und in den Kapiteln vorkommt. Tipp: Lies eine Folienformel einmal laut in ganzen Sätzen vor, bevor du rechnest.

### Zahlenmengen und Logik

| Symbol | So liest du es vor | Beispiel |
|---|---|---|
| ℕ | „die natürlichen Zahlen“: 1, 2, 3, … (manchmal mit 0) | Platznummern einer Folge: n ∈ ℕ |
| ℝ | „die reellen Zahlen“: alle Zahlen auf dem Zahlenstrahl | −2,5; 0; √2; π liegen alle in ℝ |
| ∈ | „liegt in“ oder „ist Element von“ | 3 ∈ ℕ: „3 liegt in den natürlichen Zahlen“ |
| ∉ | „liegt nicht in“ | −1 ∉ ℕ: „−1 ist keine natürliche Zahl“ |
| ⊂ | „ist Teilmenge von“: alles links liegt auch rechts | ℕ ⊂ ℝ: „jede natürliche Zahl ist auch eine reelle Zahl“ |
| ∩ | „geschnitten mit“: was in beiden Mengen liegt | [0, 5] ∩ [3, 8] = [3, 5] |
| ∀ | „für alle“ | ∀n ∈ ℕ: n ≥ 1, „für alle n aus ℕ gilt n ≥ 1“ |
| ∃ | „es gibt (mindestens ein)“ | ∃n ∈ ℕ: n > 100, „es gibt ein n, das größer als 100 ist“ |
| ⇒ | „daraus folgt“ oder „wenn …, dann …“ | x = 2 ⇒ x² = 4 (umgekehrt nicht: aus x² = 4 kann auch x = −2 folgen) |
| ⇔ | „genau dann, wenn“: gilt in beide Richtungen | x + 1 = 3 ⇔ x = 2 |
| ≈ | „ungefähr gleich“ | π ≈ 3,14 |
| ≠ | „ungleich“ | q ≠ 1: „q darf nicht 1 sein“ |
| ≤, ≥ | „kleiner oder gleich“, „größer oder gleich“ | aₙ ≤ aₙ₊₁: „das nächste Glied ist mindestens so groß“ |
| ≪ | „viel kleiner als“, bei Wachstum „wächst viel langsamer als“ | ln n ≪ n |
| ε | „Epsilon“: eine kleine positive Zahl, die gewünschte Genauigkeit | ε = 0,01 |

### Intervalle

| Symbol | So liest du es vor | Beispiel |
|---|---|---|
| (a, b) | „offenes Intervall von a bis b“: die Ränder gehören **nicht** dazu | (0, 1): 0,5 liegt drin, 0 und 1 nicht |
| [a, b] | „geschlossenes Intervall von a bis b“: die Ränder gehören dazu | [0, 1]: 0 und 1 liegen drin |
| [a, b), (a, b] | „halboffen“: nur die Seite mit eckiger Klammer gehört dazu | [0, 1): 0 ja, 1 nein |
| [a, ∞) | „von a bis unendlich“, a gehört dazu. Bei ∞ steht immer die runde Klammer, denn ∞ ist keine Zahl | [2, ∞) = alle x mit x ≥ 2 |

### Folgen und Summen

| Symbol | So liest du es vor | Beispiel |
|---|---|---|
| aₙ | „a n“ oder „a Index n“: das Glied auf Platz n | bei aₙ = n² ist a₃ = 9 |
| aₙ₊₁, aₙ₋₁ | „a n plus 1“, „a n minus 1“: das nächste und das vorige Glied | bei aₙ = n² ist aₙ₊₁ = (n + 1)² |
| (aₙ)ₙ∈ℕ | „die Folge a n, n aus ℕ“: die ganze Liste, nicht ein einzelnes Glied | (1/n)ₙ∈ℕ = 1, ½, ⅓, ¼, … |
| n₀ | „n null“: ein bestimmter Platz, ab dem etwas gilt | ab n₀ = 101 ist 1/n < 0,01 |
| Σₖ₌₁⁴ k² | „Summe von k gleich 1 bis 4 über k Quadrat“ | 1 + 4 + 9 + 16 = 30 |
| Σₖ₌₀^∞ qᵏ | „Summe von k gleich 0 bis unendlich über q hoch k“ | Σₖ₌₀^∞ (½)ᵏ = 1 + ½ + ¼ + … = 2 |
| sₙ | „s n“: die n-te Partialsumme, also der Zwischenstand | bei 1 + 2 + 4 + … ist s₂ = 1 + 2 + 4 = 7 (Start k = 0) |
| ∞ | „unendlich“: keine Zahl, sondern „ohne Ende“ | n → ∞ |
| n! | „n Fakultät“: 1 · 2 · … · n | 4! = 1 · 2 · 3 · 4 = 24 |

### Grenzwerte

| Symbol | So liest du es vor | Beispiel |
|---|---|---|
| n → ∞ | „n geht gegen unendlich“: n wird immer größer | n = 10, 100, 1000, … |
| aₙ → a | „a n geht gegen a“ | 1/n → 0 |
| lim (n → ∞) aₙ = a | „Limes von a n für n gegen unendlich ist a“. Auf Deutsch: Wohin laufen die Glieder, wenn n immer größer wird? | lim (n → ∞) 1/n = 0 |
| lim (x → a) f(x) | „Limes von f von x für x gegen a“: Wohin läuft f(x), wenn x immer näher an a heranrückt? | lim (x → 2) x² = 4 |
| x̂ | „x Dach“: eine feste Stelle auf der x-Achse (die Folie schreibt lim mit x → x̂) | x̂ = 2 |
| x → a⁺ | „x gegen a von rechts“: x kommt von größeren Werten | x = 2,1; 2,01; 2,001 → 2⁺ |
| x → a⁻ | „x gegen a von links“: x kommt von kleineren Werten | x = 1,9; 1,99; 1,999 → 2⁻ |

### Funktionen

| Symbol | So liest du es vor | Beispiel |
|---|---|---|
| f: D → W | „f bildet D nach W ab“: Man darf Zahlen aus D einsetzen, die Ergebnisse liegen in W | f: ℝ → ℝ |
| x ↦ f(x) | „x wird abgebildet auf f von x“ oder „x wird zu f von x“ | x ↦ x²: 3 ↦ 9 |
| f⁻¹ | „f hoch minus 1“ oder „Umkehrfunktion von f“: macht f rückgängig. **Nicht** 1/f | f(x) = 2x ⇒ f⁻¹(x) = x/2 |
| g ∘ f | „g nach f“ oder „g Kringel f“: zuerst f, dann g | f(x) = x + 1, g(x) = x²: (g ∘ f)(2) = g(3) = 9 |
| f\|_A | „f eingeschränkt auf A“: dieselbe Vorschrift, nur auf der Menge A | x² eingeschränkt auf [0, ∞) |
| \|x\| | „Betrag von x“: Abstand von 0, ohne Vorzeichen | \|−3\| = 3 |
| \|a − b\| | „Betrag von a minus b“: der Abstand zwischen a und b | \|2 − 5\| = 3 |
| √x | „Wurzel aus x“: welche Zahl mal sich selbst ergibt x? | √49 = 7 |
| e | „Eulersche Zahl“, ungefähr 2,718 | e² ≈ 7,389 |
| ln x | „natürlicher Logarithmus von x“: Mit welcher Hochzahl muss man e hochnehmen, um x zu bekommen? | ln e = 1, ln 1 = 0 |
