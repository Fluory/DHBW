## Brüche

Zähler/Nenner: **Zähler** oben zählt die Stücke, **Nenner** unten sagt, in wie viele Teile das Ganze geschnitten ist.

| Regel | So geht es | Beispiel |
|---|---|---|
| Kürzen | oben und unten durch dieselbe Zahl | 12/99 = 4/33 |
| Plus, Minus | erst gleicher Nenner, dann Zähler rechnen | 1/2 + 1/3 = 3/6 + 2/6 = 5/6 |
| Mal | Zähler · Zähler, Nenner · Nenner | 3/4 · 2/9 = 6/36 = 1/6 |
| Geteilt | mal Kehrwert | 3/5 : 9/10 = 3/5 · 10/9 = 2/3 |

**Doppelbruch** (3/10)/(1 − 1/10):

1. Nenner ausrechnen: 1 − 1/10 = 9/10.
2. 3/10 : 9/10 = 3/10 · 10/9 = 30/90.
3. Kürzen: **1/3**.

## Potenzen

aⁿ = a · a · … · a (n-mal) heißt: **Basis** a wird n-mal malgenommen, n ist der **Exponent**.

| Regel | Allgemein | Zahlen |
|---|---|---|
| hoch 0 | a⁰ = 1 | 5⁰ = 1 |
| negativ | a⁻ⁿ = 1/aⁿ | 2⁻³ = 1/8 |
| gleiche Basis mal | aᵐ · aⁿ = aᵐ⁺ⁿ | 3² · 3³ = 3⁵ = 243 |
| gleiche Basis geteilt | aᵐ/aⁿ = aᵐ⁻ⁿ | 2⁷/2⁴ = 2³ = 8 |
| Potenz einer Potenz | (aᵐ)ⁿ = aᵐ·ⁿ | (2³)² = 2⁶ = 64 |
| gleicher Exponent | aᵏ · bᵏ = (a · b)ᵏ | 2ᵏ · 5ᵏ = 10ᵏ |

- (−1)ᵏ ist ein Vorzeichen-Schalter: k gerade → +1, k ungerade → −1.
- Zahl zwischen −1 und 1 hoch k wird immer kleiner: (½)³ = 0,125.
- √49 = 7, weil 7 · 7 = 49. Wurzel = „hoch ½“.

Folie: (−1)ᵏ(⅕)ᵏ → auf Deutsch: gleicher Exponent, Basen zusammenfassen: (−⅕)ᵏ.

## Summenzeichen Σ

Σₖ₌ₘⁿ aₖ = aₘ + aₘ₊₁ + … + aₙ heißt: k ist die **Laufvariable** (Zeilennummer), m unten der Startwert, n oben der Endwert, aₖ die Regel für Zeile k.

1. Start und Ende ablesen.
2. Jeden Wert für k einsetzen.
3. Jeden Ausdruck ausrechnen, alles addieren.

Σₖ₌₁⁴ k² = 1 + 4 + 9 + 16 = **30**. Σₖ₌₀³ (½)ᵏ = 1,875, aber Σₖ₌₁³ (½)ᵏ = 0,875.

- Anzahl Summanden = Ende − Start + 1.
- Konstanten herausziehen: Σₖ₌₀² 3 · 2ᵏ = 3 · (1 + 2 + 4) = 21.

## Fakultät

n! = 1 · 2 · … · n heißt: alle ganzen Zahlen von 1 bis n malnehmen. 0! = 1, 3! = 6, 4! = 24, 5! = 120.

Trick: (k + 1)! = (k + 1) · k!. Damit: k!/(k + 1)! = **1/(k + 1)**. Probe k = 4: 24/120 = 1/5.

## Zinseszins

Kₙ = K₀ · (1 + i)ⁿ heißt: K₀ Startkapital, i Zinssatz als Dezimalzahl, 1 + i Wachstumsfaktor, n Jahre, Kₙ Kontostand.

1. Prozent durch 100: 5 % = 0,05.
2. Faktor: 1,05.
3. Hoch Jahre: 1,05² = 1,1025.
4. Mal Start: 100 · 1,1025 = **110,25 €**.

## Betrag

|a − b| heißt: Abstand zwischen a und b, nie negativ. Folie: |aₙ − a| < ε → auf Deutsch: „aₙ liegt weniger als ε von a entfernt.“

|x − 2| < 0,5 → von 2 aus 0,5 nach links und rechts → **1,5 < x < 2,5**.

## Rechnen mit unendlich

∞ ist keine Zahl, sondern „wird immer größer“. lim (n → ∞) 1/n = 0 → auf Deutsch: „1/n läuft gegen 0, wenn n immer größer wird.“

- Feste Zahl durch riesig → 0. Riesig plus feste Zahl → ∞.
- qⁿ mit −1 < q < 1 → 0, mit q > 1 → ∞.
- Wachstum: ln n ≪ √n ≪ n ≪ n² ≪ 2ⁿ ≪ eⁿ ≪ n!
- **Unbestimmt:** ∞ − ∞, ∞/∞, 0 · ∞ → umformen. n² − n = n(n − 1) → ∞.

## Typische Fehler

- 1/2 + 1/3 = 2/5. Nenner nie addieren.
- Summanden kürzen: (2 + 3)/2 ist 2,5, nicht 3.
- −2² = −4, aber (−2)² = 4.
- 3 · 2ᵏ ist nicht 6ᵏ. √(a + b) ist nicht √a + √b.
- Σₖ₌₀³ 2ᵏ beginnt mit 2⁰ = 1, nicht mit 0.
- (2k)! ist nicht 2 · k!: 6! = 720, 2 · 3! = 12.
- 5 % ist 0,05, nicht 0,5.
- |a + b| ist nicht immer |a| + |b|.
