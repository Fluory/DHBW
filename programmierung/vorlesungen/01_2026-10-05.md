### Teil 1: Algorithmen und Datenstrukturen
- **Algorithmus** = Schrittfolge zur systematischen Lösung eines Problems, unabhängig von der Sprache.
  Anforderungen: Endlichkeit, Ausführbarkeit, Korrektheit, Effizienz.
- Eigenschaften: **terminierend** (endet bei jeder erlaubten Eingabe), **determiniert** (gleiche
  Eingabe → gleiches Ergebnis), **deterministisch** (nächster Schritt jederzeit eindeutig).
- **Datenstrukturen** organisieren Daten für effizienten Zugriff: Array (Index, feste Größe),
  Liste (flexibel), Baum (Hierarchien), Graph (Netzwerke, Routen), Stack (LIFO, Zurück-Taste),
  Queue (FIFO, Druckaufträge). In Python eingebaut: `list`, `tuple`, `dict`, `set`.
- BWL-Beispiele: Nachbestellung, Kundenwertanalyse, Umsatzprognose, Kredit-Scoring,
  Warenkorbempfehlung, Schichtplanung, Anomalieerkennung.

### Teil 2: Von Maschinensprache zu Python
- Maschinensprache (binär) → Assembler (symbolisch, prozessorabhängig: `MOV`, `ADD`, `CMP`, `JE`)
  → höhere Sprachen ab den 1950ern.
- Heute denkt man in **Paradigmen** statt Generationen: imperativ, objektorientiert, funktional,
  deklarativ; Python ist **multiparadigmatisch**.
- Drei Übersetzungsstrategien:

| Strategie | Ablauf | Vorteil | Nachteil | Beispiele |
|---|---|---|---|---|
| Interpreter | Anweisung für Anweisung ausführen | schnelles Ausprobieren | langsamer | Shell-Skripte |
| Compiler | alles vorab in Maschinencode | schnell | nur Zielplattform, Kompilierschritt | C, C++, Rust, Go |
| Zwischencode | Bytecode + virtuelle Maschine (oft mit JIT) | portabel | Laufzeitumgebung nötig | Java, C#, Python |

- **Python**: CPython übersetzt in Bytecode, die Python-VM führt ihn aus (seit 3.13 experimenteller JIT).

### Teil 3: Einstieg in Python
- Python: 1991 von Guido van Rossum, Name nach Monty Python; Python 3 seit 2008, Python 2 tot seit 2020.
  Im Kurs: **Python 3.14**.
- Eigenschaften: plattformunabhängig, **dynamisch, aber stark typisiert** (Werte haben Typen,
  Variablen nicht), automatische Speicherverwaltung, „Batteries included“.
- Im Kurs werden trotzdem **Typangaben** geschrieben und mit `ty` geprüft.
- Syntax: Einrückung (4 Leerzeichen) bildet Blöcke, `:` leitet Block ein, kein Semikolon,
  Groß-/Kleinschreibung zählt, `#` = Kommentar.

```python
# Unser erstes Programm
print("Hello World!")
```

- Werkzeugkette: **uv** (installiert Python, verwaltet Projekte und Pakete) → **CPython 3.14** →
  Projektumgebung `.venv` mit **ruff** (Formatierung + Stil: `uv run ruff format .`, `uv run ruff check .`)
  und **ty** (Typprüfung: `uv run ty check`).
- Einrichtung:

```bash
uv python install 3.14
uv init --bare --python 3.14 prog1
cd prog1
uv add --dev ruff ty
uv run hallo.py
```

- Terminal-Basics: `pwd`, `ls`/`dir`, `cd prog1`, `cd ..`; ↑ holt letzten Befehl, Tab vervollständigt.
- Interaktive Konsole: `uv run python`, Prompt `>>>`, `exit()` zum Beenden. Notfall ohne
  Installation: python.org/shell, JupyterLite.

## Wichtige Begriffe

- **Algorithmus** – endliche, ausführbare Schrittfolge zur Problemlösung
- **determiniert / deterministisch** – gleiches Ergebnis bei gleicher Eingabe / nächster Schritt eindeutig
- **LIFO / FIFO** – Stack / Queue
- **Bytecode** – plattformunabhängiger Zwischencode, von einer VM ausgeführt
- **JIT** – Just-in-Time-Kompilierung häufig genutzten Codes zur Laufzeit
- **uv, ruff, ty** – Projekt-/Paketverwaltung, Linter/Formatierer, Typprüfer
