Aufgabe 6 · Aussagenlogik

16 Punkte

6.1(1 Punkt) Wann ist A → B falsch?

Richtig: b. Die Implikation ist nur gebrochen, wenn die Voraussetzung gilt und die Folgerung nicht. Bei A = f ist A → B immer wahr („aus Falschem folgt alles“).

6.2(1 Punkt) Welcher Satz ist gleichwertig zu „Wenn eine Zahl durch 6 teilbar ist, ist sie gerade“?

Richtig: c. Kontraposition ¬B → ¬A: Seiten tauschen und beide verneinen. Die erste Option ist die Umkehrung (4 ist gerade, aber nicht durch 6 teilbar), die zweite der Umkehrschluss (8 widerlegt ihn).

6.3(1 Punkt) Welchen Wert hat ¬A ∨ B ∧ C bei A = w, B = w, C = f?

Richtig: a. Vorrang ¬ vor ∧ vor ∨: (¬A) ∨ (B ∧ C) = f ∨ (w ∧ f) = f ∨ f = f. Die Vorrangregeln legen die Klammern eindeutig fest.

6.7 a(1 Punkt) Gilt ¬(A ∧ ¬B) ≡ ¬A ∨ B?

Richtig: a. De Morgan: ¬(A ∧ ¬B) ≡ ¬A ∨ ¬¬B ≡ ¬A ∨ B. Das ist übrigens A → B.

6.7 b(1 Punkt) Gilt (A → B) → C ≡ A → (B → C)?

Richtig: b. Bei A = B = C = f: links (f → f) → f = w → f = f, rechts f → (…) = w. Eine abweichende Zeile reicht, bei Pfeil-Ketten zählen die Klammern.

6.8(2 Punkte) Vereinfache ¬(¬A ∨ B) ∨ B mit den logischen Gesetzen. Nenne in jeder Zeile das Gesetz.

1. ¬(¬A ∨ B) ∨ B ≡ (A ∧ ¬B) ∨ B (De Morgan, doppelte Negation)

2. ≡ (A ∨ B) ∧ (¬B ∨ B) (Distributivität)

3. ≡ (A ∨ B) ∧ w (Komplement)

4. ≡ A ∨ B (Neutralität). Probe A = w, B = f: links ¬(f ∨ f) ∨ f = w, rechts w.

Aufgabe 7 · Quantoren, Beweise und Induktion

12 Punkte

7.1(1 Punkt) Was ist die Verneinung von ∀x ∃y: x < y?

Richtig: c. Jeden Quantor umdrehen, Reihenfolge behalten, ¬ nach innen: ∃x ∀y ¬(x < y) ≡ ∃x ∀y: x ≥ y. Wer nur innen verneint und die Quantoren stehen lässt, macht den häufigsten Fehler.

7.2(1 Punkt) Auf ℕ = {1, 2, 3, …}: Welche Aussage ist wahr?

Richtig: d. x = 1 ist kleiner oder gleich jeder natürlichen Zahl, also ist ∃x ∀y: x ≤ y wahr. ∀x ∃y: y < x scheitert an x = 1 (es gibt kein kleineres y in ℕ).

7.3(1 Punkt) P(x) = „x ist Primzahl“, G(x) = „x ist gerade“. Wie formalisiert man „Jede Primzahl größer als 2 ist ungerade“?

Richtig: d. „Jedes … ist …“ heißt ∀ mit →: Für alle x gilt, wenn x eine Primzahl über 2 ist, dann ist x nicht gerade. Mit ∧ statt → hieße es „jede Zahl ist eine ungerade Primzahl über 2“.

7.4(1 Punkt) Welches Beweismuster passt am besten zu „Ist n² ungerade, dann ist n ungerade“?

Richtig: b. Direkt ist n² schwer zu „entwurzeln“. Kontraposition: n = 2k ⇒ n² = 4k² = 2 · (2k²) ist gerade. Beispiele beweisen nie ein „für alle“, und ein Gegenbeispiel gibt es nicht, weil die Aussage stimmt.

7.5(1 Punkt) Was zeigt ein einziges Gegenbeispiel?

Richtig: a. Ein Gegenbeispiel widerlegt ein ∀. Um ein ∃ zu widerlegen, müsstest du zeigen, dass es für alle nicht gilt.

7.6(6 Punkte) Zeige mit vollständiger Induktion: 2 + 6 + 10 + … + (4n − 2) = 2n² für alle n ∈ ℕ.

Wert der linken Seite für n = 10

Anfang n = 1: links 4 · 1 − 2 = 2, rechts 2 · 1² = 2 ✓.

Annahme: Für ein festes n gilt 2 + 6 + … + (4n − 2) = 2n².

Schluss: Das neue Glied ist 4(n + 1) − 2 = 4n + 2. Dann 2 + … + (4n − 2) + (4n + 2) = 2n² + 4n + 2 (← Annahme) = 2(n² + 2n + 1) = 2(n + 1)² ✓.

Für n = 10: 2 · 10² = 200.

7.7(1 Punkt) Wie viele Zeilen hat die Wahrheitstafel einer Formel mit den Variablen A, B, C, D, E?

Zeilen

2⁵ = 32: Jede Variable verdoppelt die Zeilen. Genau das zeigt man auf den Folien mit Induktion.

Richtig: c. De Morgan: Das Komplement dreht ∩ zu ∪ um, wie ¬(A ∧ B) ≡ ¬A ∨ ¬B. Differenz und kartesisches Produkt sind nicht vertauschbar.

9.3(1 Punkt) Welche Eigenschaften hat „x teilt y“ auf ℕ?

Richtig: c. x teilt x (reflexiv). 2 teilt 4, aber 4 nicht 2 (nicht symmetrisch). Teilen sich x und y gegenseitig, ist x = y (antisymmetrisch, in ℕ). x | y und y | z ⇒ x | z (transitiv).

9.4(3 Punkte) Zeige, dass R₃ = {(m, n) ∈ ℤ × ℤ ∣ m − n ist durch 3 teilbar} eine Äquivalenzrelation ist.

Schreibe m R₃ n ⇔ m − n = 3k mit k ∈ ℤ.

Reflexiv: m − m = 0 = 3 · 0.

Symmetrisch: m − n = 3k ⇒ n − m = 3 · (−k), −k ∈ ℤ.

Transitiv: m − n = 3k und n − p = 3l ⇒ m − p = (m − n) + (n − p) = 3(k + l).

Mit Zahlenbeispielen allein gibt es keine Punkte: „ja“ braucht ein Argument für alle m, n, p.
