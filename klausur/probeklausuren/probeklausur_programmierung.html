Schreib die Funktionen mit Typangaben. max() und sum() sind nicht erlaubt.

5a(4 Punkte) groesster_wert(werte: list[float]) -> float gibt den größten Wert der Liste zurück. Die Liste ist nie leer.
Beispiele: groesster_wert([3, 9, 2]) → 9, groesster_wert([-5, -2, -8]) → -2

Musterlösung

def groesster_wert(werte: list[float]) -> float:
    groesster = werte[0]          # mit dem ersten Wert starten
    for wert in werte:
        if wert > groesster:
            groesster = wert
    return groesster              # nach der Schleife!

Achtung: Startest du mit groesster = 0, ist das Ergebnis bei [-5, -2, -8] falsch (0 statt −2).

5b(6 Punkte) fahrpreis(alter: int, km: float) -> float berechnet einen Busfahrpreis:

  • Grundpreis 2,00 € plus 0,30 € pro Kilometer
  • Kinder unter 6 fahren kostenlos (0.0)
  • unter 18: halber Preis
  • ab 65: 20 % Rabatt
  • Ergebnis auf 2 Nachkommastellen runden

Beispiele: fahrpreis(30, 10) → 5.0, fahrpreis(10, 10) → 2.5, fahrpreis(4, 10) → 0.0, fahrpreis(70, 10) → 4.0

Musterlösung

def fahrpreis(alter: int, km: float) -> float:
    if alter < 6:
        return 0.0
    preis = 2.0 + 0.30 * km
    if alter < 18:
        preis = preis / 2
    elif alter >= 65:
        preis = preis * 0.8
    return round(preis, 2)

Achtung, Reihenfolge: Prüfst du „unter 18“ vor „unter 6“, zahlt ein Vierjähriger den halben Preis statt nichts.

Aufgabe 8 · Klassen: Was wird ausgegeben?

2 Punkte, je Zeile 0,5
class Tier:
    def __init__(self, name: str) -> None:
        self.name = name

    def laut(self) -> str:
        return "..."

    def vorstellen(self) -> str:
        return f"{self.name} sagt {self.laut()}"


class Hund(Tier):
    def laut(self) -> str:
        return "Wuff"


class Katze(Tier):
    def __init__(self, name: str, alter: int) -> None:
        super().__init__(name)
        self.alter = alter

    def laut(self) -> str:
        return "Miau"


tiere = [Hund("Bello"), Katze("Mia", 3), Tier("Nemo")]
for tier in tiere:
    print(tier.vorstellen())
print(len(tiere), tiere[1].alter)
Bello sagt Wuff
Mia sagt Miau
Nemo sagt ...
3 3

vorstellen() steht nur in Tier, ruft aber self.laut() auf. Welches laut() läuft, entscheidet das Objekt. Das ist Polymorphie. Katze ruft mit super().__init__ den Konstruktor von Tier auf.
