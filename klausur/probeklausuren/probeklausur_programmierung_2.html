Single Choice: genau eine Antwort ist richtig, 1 Punkt pro Frage.

1.1Ein Algorithmus heißt deterministisch, wenn …

Richtig: c. Das Trio auswendig lernen: terminierend = endet immer (a). determiniert = gleiche Eingabe, gleiches Ergebnis (b). deterministisch = der Ablauf selbst ist eindeutig, es gibt nie eine Wahl zwischen zwei nächsten Schritten (c). Jeder deterministische Algorithmus ist auch determiniert, aber nicht umgekehrt.

1.2Was passiert, wenn du uv run rechner.py startest?

Richtig: b. Python ist eine interpretierte Sprache mit Zwischenschritt: Quellcode wird zu Bytecode (sichtbar als .pyc in __pycache__), den die Python-VM ausführt. Es entsteht keine .exe. uv run startet das Programm nur und prüft es nicht mit ruff.

1.3Was gilt in Python für x = 5 und danach x = "fünf"?

Richtig: a. Dynamisch typisiert heißt: Der Typ gehört zum Wert, nicht zum Namen. Ein Name darf später auf einen Wert mit anderem Typ zeigen. Python prüft das beim Ausführen nicht. Erst ty würde eine Typangabe wie x: int anmahnen. Umlaute in Strings sind erlaubt.

1.4Welches Werkzeug meldet einen ungenutzten Import und Stilprobleme?

Richtig: d. ruff ist der Linter für Stil und typische Fehler, zum Beispiel ungenutzte Importe oder Variablen. ty prüft die Typen, etwa "3" statt int. pytest führt Tests aus, und uv add fügt ein Paket hinzu.

1.5Oben im Programm steht nur import math. Welcher Aufruf funktioniert?

Richtig: b. Bei import math sprichst du alles über den Modulnamen an: math.floor(…). Ein einfaches floor(…) geht nur nach from math import floor, sonst gibt es einen NameError.

1.6Was bewirkt uv add requests im Projektordner?

Richtig: c. uv add lädt das Paket von pypi.org, trägt es in pyproject.toml ein und installiert es. Den import im Code schreibst du danach selbst.

Aufgabe 4 · Funktionen und Parameter

12 Punkte

4.1def f(n): print(n * 2). Was steht nach e = f(3) in e?

Richtig: b. print zeigt nur etwas im Terminal an. Zurückgegeben wird nur, was hinter return steht. Ohne return ist das Ergebnis None.

4.2In einer Funktion steht ergebnis = 42. Nach dem Aufruf steht außerhalb print(ergebnis), ohne dass es draußen ein ergebnis gibt. Was passiert?

Richtig: d. Eine Variable, die in einer Funktion zugewiesen wird, ist lokal. Sie existiert nur, solange der Aufruf läuft. Draußen ist der Name unbekannt.

4.3In einer Datei steht zuerst def preis(a): und weiter unten def preis(a, b):. Was gilt?

Richtig: a. Python kennt keine Überladung. Ein zweites def mit demselben Namen überschreibt das erste. Stattdessen nimmt man einen Standardwert: def preis(a, b=0):.

Aufgabe 5 · Objektorientierung

18 Punkte

5.1Was ist eine Klasse?

Richtig: c. Die Klasse ist der Bauplan (z. B. Konto). Ein Objekt ist ein konkretes Exemplar davon mit eigenen Werten (Antwort a), zum Beispiel Konto("Lea", 100).

5.2Was ist ein Instanzattribut?

Richtig: a. Instanzattribut heißt: Jedes Objekt hat seinen eigenen Wert (self.stand). Antwort b beschreibt das Klassenattribut, das direkt in der Klasse steht und für alle gemeinsam gilt (z. B. ZINS = 0.02).

5.3Eine Klasse hat weder __str__ noch __repr__. Was gibt print(k) für ein Objekt k aus?

Richtig: b. Ohne eigene Methode nimmt Python die Standardausgabe von object: Klassenname und Speicheradresse. Lesbare Ausgaben bekommst du mit __str__ oder __repr__ (bei @dataclass automatisch).

5.4Was bedeutet der Unterstrich in self._stand?

Richtig: d. Der Unterstrich ist eine Vereinbarung, Python verhindert den Zugriff nicht. Nach außen gibt man den Wert über eine @property frei. So steuerst du, ob man ihn nur lesen oder auch ändern darf.

5.5Wozu dient @override über einer Methode?

Richtig: c. @override ändert am Verhalten nichts. Es ist ein Hinweis für ty. Hast du dich im Namen vertippt (flache statt flaeche), merkt ty das. Die Oberklassen-Methode rufst du mit super() auf.

5.6Kreis erbt von der abstrakten Klasse Form, überschreibt aber die abstrakte Methode flaeche nicht. Was passiert bei Kreis("Teller", 1)?

Richtig: a. Solange eine @abstractmethod nicht überschrieben ist, gilt auch die Unterklasse als abstrakt. Der TypeError kommt schon beim Anlegen.

5.9(5 Punkte) Füll die Lücken. Das Programm soll Tisch: 3.0 und Teller: 3.14 ausgeben.

import math
from abc import ABC, abstractmethod
from typing import override


class Form((1)):
    def __init__(self, name: str) -> None:
        self.name = name

    (2)
    def flaeche(self) -> float:
        """Jede Form berechnet ihre Fläche selbst."""


class Rechteck((3)):
    def __init__(self, name: str, breite: float, hoehe: float) -> None:
        (4).__init__(name)
        self.breite = breite
        self.hoehe = hoehe

    @override
    def flaeche(self) -> float:
        return self.breite * self.hoehe


class Kreis(Form):
    def __init__(self, name: str, radius: float) -> None:
        super().__init__(name)
        self.radius = radius

    @override
    def flaeche(self) -> float:
        return round(math.pi * self.radius**2, 2)


formen: list[Form] = [Rechteck("Tisch", 2, 1.5), Kreis("Teller", 1)]
for f in formen:
    print(f"{f.name}: {f.(5)()}")

(2)
(3)
(4)
(5)

(1) ABC · (2) @abstractmethod · (3) Form · (4) super() · (5) flaeche

Polymorphie: Dieselbe Zeile f.flaeche() rechnet beim Rechteck 2 · 1,5 = 3.0 und beim Kreis π · 1² ≈ 3.14. Welche Methode läuft, entscheidet das Objekt.

Falle bei (4): Form.__init__(name) geht nur als Form.__init__(self, name). Mit super() fällt das self weg.
