Block 9: Lösungen RechnerarchitekturKlausur-Aufgabe 9 (8 P)

P9.1

  • Rechenwerk (ALU): Rechenoperationen und boolesche Verknüpfungen.
  • Steuerwerk (Control Unit): interpretiert die Befehle, verschaltet Datenquelle, Datensenke und ALU, regelt die Befehlsfolge.
  • Bussystem: Kommunikation zwischen den Komponenten (Steuer-, Adress-, Datenbus).
  • Speicherwerk (RAM): speichert Programme und Daten.
  • Ein-/Ausgabewerk: Ein-/Ausgabe zum Anwender (Tastatur, Bildschirm) oder zu anderen Systemen.

P9.2

  1. FETCH: Befehl von der Adresse im Befehlszähler aus dem Speicher ins Befehlsregister laden.
  2. DECODE: Steuerwerk erkennt „Lade in den Akkumulator“ und erzeugt die Schaltinstruktionen.
  3. FETCH OPERANDS: Wert von Adresse NUM1 aus dem Speicher holen.
  4. EXECUTE: Wert in den Akkumulator schreiben.
  5. UPDATE INSTRUCTION POINTER: Befehlszähler zeigt auf den nächsten Befehl (CLC). Dann beginnt der Zyklus von vorn.

Jede Phase kann mehrere Takte dauern; Befehl und Operand laufen nacheinander über denselben Bus.

P9.3

Vorteile Von-Neumann: einfache Implementierung, geringere Kosten; Universalrechner – Programme liegen wie Daten im Speicher und können zur Laufzeit geladen und geändert werden.

Nachteile: Von-Neumann-Flaschenhals – Befehle und Daten müssen nacheinander über den gemeinsamen Bus, mindestens 2 Taktzyklen pro Anweisung. Sicherheit – weil Code und Daten im selben Speicher liegen, kann als Daten getarnter Code eingeschleust werden (z. B. über Buffer-Überläufe).

Harvard: getrennte Speicher und Busse, Befehl und Daten in einem Schritt, schneller – aber in der Regel teurer. Einsatz daher v. a. in Mikrocontrollern, Signalverarbeitung, KI-Spezialrechnern, zunehmend in PCs/Servern.

P9.4

a) Befehlszähler: verweist auf (enthält die Adresse von) den nächsten auszuführenden Befehl. Befehlsregister: enthält den momentan auszuführenden Befehl selbst.

b) Befehle aus dem Hauptspeicher abrufen und Befehlstyp bestimmen; Operanden in Register laden; Rechenwerk zur Operation veranlassen; bestimmen, wo es (ggf. abhängig vom Ergebnis) weitergeht.

c) Kleiner Hochgeschwindigkeitsspeicher in der CPU für jeweils einen Wert; Daten-Schnittstelle zum Rechenwerk.

P9.5

  • Beim Von-Neumann-Rechner liegen Programme und Daten im selben Speicher.richtig: Kernmerkmal.
  • Die Harvard-Architektur verwendet getrennte Busse für Befehle und Daten.richtig: Daher Befehl und Daten in einem Schritt.
  • Der Adressbus überträgt bei einem Lesezugriff die gelesenen Daten zur CPU.falsch: Daten laufen über den Datenbus; der Adressbus trägt die Adresse.
  • Peripherie wird in der Regel seriell angebunden, z. B. über USB.richtig: USB = Universal Serial Bus; Adress-/Datenbus sind parallel.
  • Die Harvard-Architektur ist in der Regel billiger als die Von-Neumann-Architektur.falsch: Umgekehrt: Harvard ist in der Regel teurer.
  • Der Von-Neumann-Zyklus besteht aus FETCH, DECODE, FETCH OPERANDS, EXECUTE und UPDATE INSTRUCTION POINTER.richtig: Fünf Phasen laut Folie.

P9.6

Steuerbus: Schreibbefehl · Adressbus: Adresse der Speicherzelle · Datenbus: Daten von der CPU zur Speicherzelle. Parallel: viele Leitungen übertragen gleichzeitig mehrere Bits (z. B. Apple M1: 64-Bit-Adressbus, 128-Bit-Datenbus); seriell: Bit für Bit nacheinander.

P10.4

Die CPU wird immer schneller als der Hauptspeicher; den ganzen Speicher auf die CPU zu bringen wäre zu teuer. Kompromiss: kleiner, sehr schneller Cache in bzw. vor der CPU (L1–L3). Idee Lokalität: Programme greifen in kurzer Zeit nur auf einen kleinen Teil des Speichers zu, deshalb werden beim Zugriff auf ein Wort auch dessen Nachbarn in den Cache geladen. Beispiele: Schleifen (derselbe Code mehrfach), Arrays/Tabellen (benachbarte Datensätze). Cache-Miss: Der Bereich liegt wider Erwarten nicht im Cache und muss über den Bus aus dem Speicher nachgeladen werden.

P10.5

  • Der Inhalt des Arbeitsspeichers (RAM) geht ohne Strom verloren.richtig: RAM ist volatil.
  • Flash-Speicher (früher ROM/EPROM) behält seinen Inhalt auch stromlos.richtig: persistent; z. B. BIOS/Firmware.
  • Register sind langsamer als der L1-Cache.falsch: Register sind der schnellste Speicher.
  • Die kleinste über den Adressbus adressierbare Einheit ist üblicherweise das Byte.richtig: 8-Bit-Zelle.
  • RAID 0 spiegelt die Daten auf eine zweite Platte.falsch: Das ist RAID 1; RAID 0 = Striping ohne Redundanz.
  • Beim Harvard-Rechner werden Daten- und Programmspeicher getrennt adressiert.richtig: Folie Speicherarten.
