def bestellwert(preise: list[float], mengen: list[int], rabatt: float = 0.0) -> float:
    """Berechnet den Wert einer Bestellung nach Rabatt.

    Args:
        preise: Stückpreise der Positionen in Euro.
        mengen: Bestellmengen, passend zu preise.
        rabatt: Rabatt als Anteil zwischen 0 und 0.5, Standard 0.0.

    Returns:
        Den Bestellwert in Euro, auf zwei Nachkommastellen gerundet.
    """

        rabatt = 0.0
    summe = 0.0

Lösung A11: Konzeptfragen8 P

  1. Parameter ist der Platzhalter in der Definition (def begruessung(name: str) → name), Argument der konkrete Wert beim Aufruf (begruessung("Bob") → "Bob").
  2. Vorteil: elegant und kurz bei selbstähnlichen Problemen, mathematische Definition direkt umsetzbar, wenig Zustand. Nachteil: speicherintensiv (ein Rahmen pro Aufruf, RecursionError ab ca. 1000 Ebenen), langsamer, schwerer zu debuggen.
  3. Kapselung: Ein Objekt schützt seinen inneren Zustand und bestimmt selbst, wie er geändert wird; nach außen nur das Nötige. Mittel in Python: Unterstrich-Konvention (_kontostand) und Properties (@property, ggf. mit Setter, der prüft).
  4. __name__ ist nur beim direkten Start "__main__". Wird die Datei importiert (z. B. von einer Testdatei), läuft main() nicht los – die Funktionen lassen sich wiederverwenden und testen.
Erwartungshorizont
  • je Teilaufgabe 2 P: Kernaussage 1 P, Beispiel/zweiter Aspekt 1 P

    bestaende: list[int], meldebestaende: list[int], hoechstbestaende: list[int]

    Liegt der Bestand unter dem Meldebestand, wird bis zum Höchstbestand
    aufgefüllt, sonst wird nichts bestellt (Menge 0).

    Args:
        bestaende: Aktuelle Bestände je Artikel.

            mengen.append(0)

Lösung 1.4: Einen Algorithmus aufschreiben

  1. Antrag entgegennehmen: Zeitraum und Anzahl Urlaubstage ablesen.
  2. Resturlaub nachsehen. Reicht er nicht: ablehnen, weiter mit 6.
  3. Prüfen, ob der Zeitraum in einer Sperrzeit liegt. Ja: ablehnen, weiter mit 6.
  4. Prüfen, ob eine Vertretung eingetragen ist. Nein: zurück an Antragsteller, weiter mit 6.
  5. Antrag genehmigen, Resturlaub um die Tage verringern.
  6. Entscheidung mitteilen. Fertig.

Jeder Zweig endet (Endlichkeit), jeder Schritt ist konkret ausführbar. „Antrag kurz ansehen“ ist nicht ausführbar/eindeutig: Was genau wird geprüft, und was passiert bei einer Abweichung? (vgl. Musterlösung VL01, Aufgabe 2)

    def bestand(self) -> int:

@dataclass

    name: str
    email: str

    produkt: Produkt
    menge: int

    def summe(self) -> Decimal:
        return self.produkt.preis * self.menge

    def __init__(self, kunde: Kunde) -> None:
        self.kunde = kunde
        self.positionen: list[Position] = []

            print(f"Nur noch {produkt.bestand} x {produkt.name} auf Lager.")
            return
        self.positionen.append(Position(produkt, menge))

        summe = Decimal(0)
        for position in self.positionen:
            summe += position.summe()
        return summe

        for p in self.positionen:
