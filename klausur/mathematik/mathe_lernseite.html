0.3 Wurzeln G

Die Wurzel √a ist die positive Zahl, die mal sich selbst a ergibt: √49 = 7, weil 7 · 7 = 49. Wurzeln sind Potenzen mit Bruch-Exponent: √a = a½. Darum gilt beim Rechnen √n = n0,5, das ist „eine halbe Potenz von n“.

  • √a · b = √a · √b: √4 · 9 = 2 · 3 = 6 ✓ (√36 = 6)
  • √14 = 12, denn ½ · ½ = ¼
  • √5 ≈ 2,2360679775 ist keine glatte Zahl. Die Heron-Folge (Aufgabe F-5) nähert sie mit Brüchen an.
  • √n wächst, aber langsamer als n: √100 = 10, √10000 = 100.

Achtung: √a + b ist nicht √a + √b. Probe: √9 + 16 = √25 = 5, aber √9 + √16 = 3 + 4 = 7.

Stufe 1 · leicht Aufgabe G4 · Wurzeln · eigene Aufgabe

a) √49 · b) √14 · c) Schreibe √n als Potenz. · d) Stimmt √16 + 9 = 4 + 3?

Lösung Schritt für Schritt

a) 7, denn 7 · 7 = 49.

b) 12, denn ½ · ½ = ¼.

c) √n = n½ = n0,5.

d) Nein. √16 + 9 = √25 = 5, aber 4 + 3 = 7. Wurzeln darf man nicht über ein Plus verteilen.

0.4 Das Summenzeichen Σ lesen und ausschreiben GK

Σ (großes griechisches S, „Sigma“) heißt einfach: „Zähle zusammen“. Es ist eine Kurzschrift für eine lange Plus-Kette. So liest man es:

Ausschreiben in drei Schritten:

  1. Setze für k nacheinander jeden Wert vom Start bis zum Ende ein: k = 1, 2, 3, 4.
  2. Rechne den Ausdruck für jeden Wert aus: 1² = 1, 2² = 4, 3² = 9, 4² = 16.
  3. Zähle alles zusammen: 1 + 4 + 9 + 16 = 30.
4Σk=1 k2 = 1 + 4 + 9 + 16 = 30

Der Startindex ändert alles

Derselbe Ausdruck mit anderem Start ergibt eine andere Summe. Das ist die häufigste Falle bei der geometrischen Reihe:

3Σk=0 (½)k = (½)0 + (½)1 + (½)2 + (½)3 = 1 + 0,5 + 0,25 + 0,125 = 1,875
3Σk=1 (½)k = (½)1 + (½)2 + (½)3 = 0,5 + 0,25 + 0,125 = 0,875

Beim Start k = 0 ist das erste Glied 1 (denn alles hoch 0 ist 1). Beim Start k = 1 ist das erste Glied ½. Merke dir: Immer zuerst das erste Glied ausrechnen.

  • Anzahl der Summanden = Ende − Start + 1. Von k = 2 bis 5 sind es 5 − 2 + 1 = 4 Summanden.
  • Konstante Faktoren darf man herausziehen: 2Σk=0 3 · 2k = 3 + 6 + 12 = 21 = 3 · (1 + 2 + 4) = 3 · 2Σk=0 2k. Das hat Dr. Wortel beim Sparplan gemacht (r vor die Summe).
  • ∞ oben heißt: Es hört nie auf. ∞Σk=1 1k = 1 + ½ + ⅓ + ¼ + … Was so eine „unendliche Summe“ bedeutet, klärt Kapitel 2.

a) k = 1, 2, 3, 4 einsetzen: 1 + 4 + 9 + 16 = 30.

b) k = 0, 1, 2, 3: 20 + 21 + 22 + 23 = 1 + 2 + 4 + 8 = 15. Achtung: Das erste Glied ist 20 = 1, nicht 0.

c) Der Ausdruck ist immer 1, und k läuft von 2 bis 5, das sind 5 − 2 + 1 = 4 Summanden: 1 + 1 + 1 + 1 = 4.

d) k = 0 bis 4: 1 − 1 + 1 − 1 + 1 = 1.

0.6 Prozent und Zinsen als Dezimalzahl G

„Prozent“ heißt „von hundert“. In jede Formel setzt man den Zinssatz als Dezimalzahl ein, nie als „5“:

Warum 1 + i? 100 € bei 5 % Zinsen: Du behältst die 100 € und bekommst 5 € dazu. 100 + 0,05 · 100 = 100 · (1 + 0,05) = 100 · 1,05 = 105 €. „Mal 1,05“ heißt also „plus 5 %“. Nach zwei Jahren: 100 · 1,05 · 1,05 = 100 · 1,052 = 110,25 €.

0.7 Der Betrag |x| als Abstand G

Der Betrag macht aus jeder Zahl ihren Abstand zur 0, also eine Zahl ohne Minus: |−3| = 3, |3| = 3, |0| = 0. Viel wichtiger für die Vorlesung: |a − b| ist der Abstand zwischen a und b auf dem Zahlenstrahl. |2 − 5| = |−3| = 3, und 2 und 5 liegen ja auch 3 auseinander.

In der Definition des Grenzwerts steht |an − a| < ε. Das liest man: „Der Abstand von an zum Grenzwert a ist kleiner als ε.“ Beispiel: |x − 2| < 0,5 heißt „x ist weniger als 0,5 von der 2 entfernt“, also 1,5 < x < 2,5.

Stufe 1 · leicht Aufgabe G9 · Betrag und Abstand · eigene Aufgabe

a) |−7| · b) |2 − 5| · c) Für welche x gilt |x − 2| < 0,5? · d) Übersetze |an − 3| < 0,01 in Worte.

Lösung Schritt für Schritt

a) 7. · b) |−3| = 3 (Abstand von 2 und 5).

c) x darf höchstens 0,5 von 2 weg sein: 1,5 < x < 2,5.

d) „Das Glied an ist weniger als 0,01 von 3 entfernt“, also 2,99 < an < 3,01.

Wer gewinnt? Die Wachstums-Rangliste

Wenn zwei Ausdrücke gegeneinander antreten, gewinnt der, der schneller wächst. Von langsam nach schnell:

ln n ≪ √n ≪ n ≪ n2 ≪ n3 ≪ 2n ≪ en ≪ n!

Zahlenprobe bei n = 20: ln 20 ≈ 3, √20 ≈ 4,5, 20² = 400, 220 ≈ 1 Million, 20! ≈ 2,4 · 1018. Darum geht 3nln n → ∞ (n schlägt ln n, Aufgabe F-4f) und xkk! → 0 (k! schlägt alles, Aufgabe R-4b).

1.1 Was ist eine Folge? D

Definition (F. 7): Eine (reelle) Folge ist eine Funktion a: ℕ → ℝ, n ↦ an. Man schreibt sie als a1, a2, a3, … Die Zahlen an heißen Glieder, n heißt Index.

In einfachen Worten: Jeder Platznummer n = 1, 2, 3, … wird genau eine Zahl an zugeordnet. „ℕ → ℝ“ heißt: rein kommt eine natürliche Zahl (die Platznummer), raus kommt eine reelle Zahl (der Wert). Der Index ist die „Platznummer“ (F. 10), wie die Startnummer bei einem Lauf.

Platz n12345…10
an = 1n10,50,3330,250,2…0,1
  • Der Index kann bei jeder ganzen Zahl beginnen, oft bei 0 oder 1. Der Buchstabe ist egal: an, bk, ci (F. 7).
  • Wichtig ist der Unterschied zwischen Index und Wert: Bei an = 1n ist a4 der 4. Platz, sein Wert ist 0,25.

1.2 Explizit und rekursiv DR

Das Bildungsgesetz ist die Regel, mit der man das n-te Glied ausrechnet. Es gibt zwei Arten (F. 8–10):

Explizit: direkte FormelMan setzt n ein und ist fertig.
an = n2: a5 = 25 sofort.
bn = (−1)n · 1n: −1; ½; −⅓; ¼ …
cn = 12n ab n = 0: 1; ½; ¼; ⅛ …
Rekursiv: aus dem VorgängerMan braucht einen Startwert und eine Regel „neues Glied aus altem“.
Fakultät: a1 = 1, an = n · an−1: 1; 2; 6; 24; 120
Um a5 zu bekommen, muss man a1 bis a4 rechnen.

Beispiel: Heron-Folge für √2 (F. 9)

Startwert a1 = 2, Regel an = 12(an−1 + 2an−1). Schritt für Schritt:

  • a2 = ½ · (2 + 22) = ½ · (2 + 1) = 1,5
  • a3 = ½ · (1,5 + 21,5) = ½ · (1,5 + 1,3333) = 1,41667
  • a4 = ½ · (1,41667 + 1,41176) = 1,414216 – schon fast √2 = 1,414214

Eine alternierende Folge wechselt ständig das Vorzeichen, meist durch den Faktor (−1)n (F. 10).

1.4 Monotonie DR

Definition (F. 14): Eine Folge heißt

  • monoton wachsend, wenn an ≤ an+1 für alle n: Die Glieder werden nie kleiner.
  • monoton fallend, wenn an ≥ an+1 für alle n: Die Glieder werden nie größer.
  • streng monoton wachsend/fallend, wenn sogar < bzw. > gilt: Jedes Glied ist echt größer/kleiner als das vorige.

Wie prüft man das? Der Differenz-Test

  1. Schreibe an+1 hin: Ersetze in der Formel jedes n durch (n + 1).
  2. Rechne an+1 − an aus und vereinfache.
  3. Ist das Ergebnis für alle n > 0, ist die Folge streng wachsend. Ist es < 0, streng fallend. Wechselt das Vorzeichen, ist sie nicht monoton.
Folge (F. 15)erste Gliederan+1 − anErgebnis
an = n21, 4, 9, 16(n + 1)2 − n2 = 2n + 1 > 0streng wachsend
bn = 1n1; 0,5; 0,33; 0,251n + 1 − 1n = −1n(n + 1) < 0streng fallend
cn = (−1)n−1, 1, −1, 1+2, −2, +2, … wechseltnicht monoton

Quotienten-Test (nur wenn alle Glieder positiv sind): an+1an > 1 heißt wachsend, < 1 fallend. Für an = 2n ist 2n+12n = 2 > 1 → streng wachsend.

Achtung: Eine konstante Folge wie en = 7 ist monoton wachsend und monoton fallend (denn 7 ≤ 7 und 7 ≥ 7), aber nicht streng. Das war die Falle in F-2e.

1.5 Beschränktheit D

Definition (F. 16): Eine Folge heißt nach oben beschränkt, wenn es eine Zahl K gibt mit an ≤ K für alle n. Sie heißt nach unten beschränkt, wenn es ein k gibt mit k ≤ an für alle n. Beschränkt heißt beides; gleichwertig: |an| ≤ C für alle n.

In einfachen Worten (F. 18): Die Folge bleibt in einem Streifen zwischen zwei festen Werten. Sie überschreitet nie eine Decke und unterschreitet nie einen Boden.

1.6 Grenzwert und Konvergenz D

Definition (F. 20): Eine Folge an heißt konvergent gegen a, wenn es für jede noch so kleine Zahl ε > 0 einen Index n0 gibt, so dass alle Glieder mit n ≥ n0 im Intervall (a − ε, a + ε) liegen. Man schreibt limn → ∞ an = a oder an → a.

∀ε > 0 ∃n0 ∈ ℕ : |an − a| < ε für alle n ≥ n0

Bild dazu: der ε-Schlauch. Zeichne um den Grenzwert a einen Streifen der Breite ε nach oben und unten. Konvergenz heißt: Ab einem Platz n0 sind alle Punkte im Schlauch und bleiben drin. Und das klappt für jeden noch so schmalen Schlauch, man muss dann nur weiter hinten anfangen.

Mit Zahlen: an = 1n → 0

Was Konvergenz bedeutet (F. 24): Sie macht „Näherung“ genau. Du gibst eine Genauigkeit vor, und ab einem Index ist sie erreicht. Es geht nie um einzelne Glieder, sondern um das Verhalten von „fast allen“ Gliedern. Am Anfang darf die Folge machen, was sie will.

Beispiele der Folie F. 22: 1n → 0 · 1 − 1n → 1 · (½)n → 0.

1.7 Divergenz: bestimmt und unbestimmt DK

Eine Folge, die nicht konvergiert, heißt divergent (F. 21). Es gibt zwei Sorten:

bestimmt divergentDie Glieder werden beliebig groß (→ +∞) oder beliebig klein (→ −∞). Man schreibt trotzdem limn→∞ an = ∞, aber ∞ ist kein Grenzwert im Sinn der Konvergenz.
Beispiel: n2: 1, 4, 9, 16 … → +∞
unbestimmt divergentDie Folge springt hin und her und hat gar keine Richtung.
(−1)n: −1, 1, −1, 1 … (bleibt beschränkt!)
(−1)n · n: −1, 2, −3, 4 … (wird betragsmäßig groß, aber mit wechselndem Vorzeichen, darum nicht „→ ∞“)

Achtung: „bestimmt divergent“ klingt nach „konvergent gegen ∞“, ist aber divergent. Auf die Frage „Ist die Folge konvergent?“ lautet die Antwort bei n2: „Nein, sie ist bestimmt divergent gegen +∞.“

1.8 Nullfolgen und Sätze über konvergente Folgen DK

Eine Folge mit Grenzwert 0 heißt Nullfolge. Die zwei wichtigsten (F. 25):

limn→∞ 1n = 0   und   limn→∞ qn = 0 für |q| < 1

Zahlenprobe für qn: 0,510 ≈ 0,00098 · (−0,5)10 ≈ 0,00098 · 0,950 ≈ 0,005. Auch negative q zwischen −1 und 1 gehen gegen 0, sie springen nur dabei um die 0 herum.

Drei Sätze (F. 25)

  1. Eindeutigkeit: Eine Folge hat höchstens einen Grenzwert.
  2. Konvergent ⇒ beschränkt: Jede konvergente Folge bleibt in einem Streifen.
  3. Monotonie-Kriterium: Beschränkt und monoton ⇒ konvergent. Beispiel: 1 − 1n ist wachsend (0; 0,5; 0,67; 0,75 …) und nie größer als 1, also konvergiert sie (gegen 1).

Achtung, die Lieblingsfalle: Die Pfeile gelten nur in eine Richtung. „Divergent“ heißt nicht „unbeschränkt“: (−1)n ist beschränkt, aber divergent. Und „beschränkt“ allein reicht nicht für Konvergenz; erst beschränkt + monoton reicht.

1.9 Rechenregeln für Grenzwerte R

Wenn an → a und bn → b (beide konvergent!), dann darf man Grenzwerte einfach „durchrechnen“ (F. 26):

c · an → c · a   an ± bn → a ± b   an · bn → a · b   anbn → ab (nur falls b ≠ 0)

Damit zerlegt man eine komplizierte Folge in Bausteine, deren Grenzwert man kennt. Die Folienbeispiele (F. 27):

  • an = 1n + 2n2: Baustein 1n → 0, Baustein 2n2 = 2 · 1n · 1n → 2 · 0 · 0 = 0. Summe: 0 + 0 = 0.
  • bn = (3 + 100e−n) · 8 · (½)n: e−n → 0, also Klammer → 3 + 0 = 3. (½)n → 0. Produkt: 3 · 8 · 0 = 0. Die 100 vor e−n ändert nichts.
  • cn = 2n2 − 3n2 + n + 1 → 2 und dn = −5n + 14n2 − 7 → 0: Hier geht es nicht direkt, weil Zähler und Nenner gegen ∞ laufen („∞∞“). Dafür gibt es das Rezept im nächsten Abschnitt.

1.10 Das Rezept „durch die höchste Potenz teilen“ RK

Für Brüche aus Potenzen von n (Polynome) gibt es ein Verfahren, das immer klappt:

  1. Suche die höchste Potenz von n im Nenner. Bei 2n2 − 3n2 + n + 1 ist das n2.
  2. Teile jeden einzelnen Summanden in Zähler und Nenner durch diese Potenz: 2n2n2 − 3n2n2n2 + nn2 + 1n2 = 2 − 3n21 + 1n + 1n2
  3. Jeder Rest der Form Zahlnp geht gegen 0: 3n2 → 0, 1n → 0.
  4. Rest ausrechnen: 2 − 01 + 0 + 0 = 2.

Zahlenprobe mit n = 1000: 2 · 1000000 − 31000000 + 1000 + 1 = 19999971001001 ≈ 1,998. Passt zu 2.

Zweites Folienbeispiel: −5n + 14n2 − 7, höchste Nennerpotenz n2: −5n + 1n24 − 7n2 → 0 + 04 − 0 = 0.

2.2 Was „eine Reihe konvergiert“ heißt DK

Konvergenz einer Reihe heißt: Die Partialsummen sn haben für n → ∞ einen endlichen Grenzwert s. Dann schreibt man ∞Σk=1 ak = s und nennt s den Wert der Reihe. Gibt es keinen endlichen Grenzwert, ist die Reihe divergent. Beim Kuchen: sn → 1, also ∞Σk=1 (½)k = 1. Unendlich viele Summanden, aber eine endliche Summe.

Achtung, zwei verschiedene Folgen: Die Folge der Summanden ak (½; ¼; ⅛ … → 0) und die Folge der Partialsummen sn (0,5; 0,75; 0,875 … → 1). Der Wert der Reihe ist der Grenzwert der Partialsummen. „Die Glieder gehen gegen 0, also ist die Reihe 0“ ist falsch.

Wozu dann Kriterien? (Rückfrage am 04.11.) Bei den meisten Reihen kann man den Wert gar nicht ausrechnen. Für Σ 1/k5 gibt es keine einfache Formel. Ein Konvergenzkriterium beantwortet nur die Ja/Nein-Frage „Gibt es einen endlichen Grenzwert?“, ohne ihn zu berechnen. Darum steht bei R-4: „Ein Grenzwert braucht nicht angegeben zu werden.“ Ausrechnen kann man den Wert nur in Sonderfällen, vor allem bei der geometrischen Reihe.

2.3 Die endliche geometrische Reihe R

Eine geometrische Reihe addiert die Glieder einer geometrischen Folge: erstes Glied v0, und jedes weitere ist das vorige mal q. Für endlich viele Glieder (k = 0 bis n) gibt es eine fertige Formel; so stand sie an der Tafel:

v0 + v0q + v0q2 + … + v0qn = nΣk=0 v0 qk = v0 · 1 − qn+11 − q   (q ≠ 1)

Achte auf den Exponenten n + 1: Von k = 0 bis k = n sind es n + 1 Summanden. Das ist dieselbe Formel wie auf Folie F. 32 (Sn = a1 · qn − 1q − 1 für n Glieder), nur anders gezählt. Zähler und Nenner mal (−1) zu nehmen ändert nichts: 1 − qn1 − q = qn − 1q − 1.

Zahlenproben:

  • 4Σk=0 2k = 1 + 2 + 4 + 8 + 16 = 31. Formel: 1 − 251 − 2 = 1 − 32−1 = 31 ✓
  • 3Σk=0 (½)k = 1 + 0,5 + 0,25 + 0,125 = 1,875. Formel: 1 − (½)41 − ½ = 1 − 0,06250,5 = 0,93750,5 = 1,875 ✓
Warum stimmt die Formel? (Ergänzung, kurz)

Nenne die Summe S = 1 + q + q2 + … + qn. Dann ist q · S = q + q2 + … + qn+1. Zieht man beides voneinander ab, fallen alle mittleren Glieder weg: S − qS = 1 − qn+1. Links S ausklammern: S · (1 − q) = 1 − qn+1, also S = 1 − qn+11 − q. Mit dem Startglied v0 kommt nur der Faktor v0 davor.

2.7 Die harmonische Reihe – die große Falle DK

∞Σk=1 1k = 1 + 12 + 13 + 14 + … = ∞   (divergent)

Die Glieder 1k gehen gegen 0, und trotzdem wird die Summe unendlich groß. Nur sehr langsam: s10 ≈ 2,93; s100 ≈ 5,19; s1 000 000 ≈ 14,39. Aber es gibt keine Decke.

Warum? Man fasst Glieder in Gruppen zusammen, von denen jede mindestens ½ ergibt:

1 + ½ + (⅓ + ¼) + (⅕ + ⅙ + 1/7 + ⅛) + …
⅓ + ¼ ≥ ¼ + ¼ = ½
⅕ + ⅙ + 1/7 + ⅛ ≥ 4 · ⅛ = ½
die nächsten 8 Glieder ≥ 8 · 1/16 = ½ …

Unendlich viele Gruppen, jede mindestens ½: Das ist ½ + ½ + ½ + … = ∞.

Merksatz: ak → 0 ist notwendig (muss sein), aber nicht hinreichend (reicht nicht). Die harmonische Reihe ist der Beweis.

2.10 Das Quotientenkriterium R

Idee: Man schaut, um welchen Faktor ein Glied im Vergleich zum vorigen schrumpft. Schrumpft es am Ende immer um einen Faktor kleiner als 1, verhält sich die Reihe wie eine konvergente geometrische Reihe.

L = limk→∞ |ak+1ak|   L < 1: konvergent   L > 1: divergent   L = 1: keine Aussage

Vorgehen in vier Schritten

  1. ak+1 hinschreiben: überall k durch (k + 1) ersetzen.
  2. Bruch ak+1ak bilden: Doppelbruch = „mal Kehrwert“.
  3. Kürzen. Die Helfer: qk+1qk = q und k!(k + 1)! = 1k + 1.
  4. Grenzwert L für k → ∞ bestimmen und mit 1 vergleichen.

Beispiel 1: ∞Σk=1 k2k

ak+1ak = k + 12k+1 · 2kk = k + 1k · 2k2k+1 = k + 1k · 12 → 1 · 12 = 12
L = ½ < 1 ⇒ konvergent

Beispiel 2: ∞Σk=0 1k!

ak+1ak = 1(k + 1)! · k!1 = k!(k + 1) · k! = 1k + 1 → 0
L = 0 < 1 ⇒ konvergent   (Ergänzung: der Wert ist e ≈ 2,718)

Wann sagt es nichts? L = 1

Bei Σ 1k ist ak+1ak = kk + 1 → 1, bei Σ 1k2 ist es k2(k + 1)2 → 1. Beide haben L = 1, aber die erste divergiert und die zweite konvergiert. Bei Brüchen aus Potenzen ist L immer 1, darum nimmt man dort die Potenzabstand-Regel.

Die Aufgabe R-4 übt genau diese Kriterienwahl. Sie steht unten bei den Aufgaben.

2.12 Teleskopsumme: wenn sich fast alles weghebt R

Neben der geometrischen Reihe gibt es einen zweiten Sonderfall, bei dem man den Wert einer Reihe ausrechnen kann: die Teleskopsumme. Der Name kommt vom Fernrohr, das man zusammenschieben kann: Die lange Summe schiebt sich auf zwei Stücke zusammen.

Bild dazu: Du fährst mit dem Zug von Stuttgart über Heilbronn und Würzburg nach Fulda. Jede Klammer ist eine Teilstrecke („Stuttgart bis Heilbronn“, „Heilbronn bis Würzburg“, …). Für die ganze Fahrt zählt nur, wo du eingestiegen und wo du ausgestiegen bist. Die Zwischenhalte heben sich weg.

Erst ganz einfach, mit kleinen Zahlen

(5 − 3) + (3 − 2) + (2 − 1) = 5 − 3 + 3 − 2 + 2 − 1
−3 und +3 heben sich weg, −2 und +2 heben sich weg ⇒ Ergebnis = 5 − 1 = 4   (Probe: 2 + 1 + 1 = 4 ✓)

Es bleiben nur das allererste und das allerletzte Stück übrig. Genau das passiert in Reihen, deren Glied die Form „etwas mit k minus dasselbe mit k + 1“ hat:

nΣk=1 (bk − bk+1) = (b1 − b2) + (b2 − b3) + … + (bn − bn+1) = b1 − bn+1

Für die unendliche Reihe lässt man dann n → ∞ laufen. Geht bn+1 → 0, ist der Wert einfach b1, also das erste Stück.

Das Rezept in vier Schritten

  1. Zerlegen: Das Glied als Differenz schreiben, z. B. 1k(k + 1) = 1k − 1k + 1. Meist steht das als Tipp dabei. Prüfen durch Gleichnamig-Machen (0.1).
  2. Ausschreiben: Die ersten 3 Glieder und das letzte Glied (mit n) hinschreiben, als Klammern.
  3. Wegstreichen: Was sich weghebt, durchstreichen. Übrig bleibt die Partialsumme sn als kurze Formel.
  4. Grenzwert: n → ∞ in sn einsetzen. Probe: s3 einmal direkt ausrechnen.

Achtung: Nur Klammern vom Typ „bk − bk+1“ (Abstand 1) heben sich so schön weg, dass nur je ein Stück am Anfang und am Ende bleibt. Ist der Abstand 2 (z. B. 1k − 1k + 2), bleiben am Anfang zwei Stücke übrig (Aufgabe B2.16).

Die Teleskopsumme passt zur Potenzabstand-Regel (2.9): 1k(k + 1) = 1k2 + k hat Abstand 2 > 1, ist also konvergent. Die Regel sagt nur „konvergent“, die Teleskopsumme liefert zusätzlich den Wert. Die Aufgabe dazu war R-5 auf Folie 55:

3.2 Sparplan: jedes Jahr r einzahlen DR

Jetzt zahlst du jedes Jahr denselben Betrag r ein, insgesamt n Mal. Jede Einzahlung wird für sich verzinst, aber unterschiedlich lange. Beispiel n = 3, r = 100 €, i = 5 %, Einzahlung jeweils am Jahresende:

Die Herleitung von der Tafel, Schritt für Schritt:

  1. Endwert = Summe aller einzeln verzinsten Einzahlungen. Die letzte Einzahlung hat 0 Jahre Zinsen, die vorletzte 1 Jahr, …, die erste n − 1 Jahre:
    En = r + r(1 + i) + r(1 + i)2 + … + r(1 + i)n−1 = n−1Σk=0 r(1 + i)k
  2. r vor die Summe ziehen (r ist in jedem Summanden derselbe Faktor):
    En = r · n−1Σk=0 (1 + i)k
  3. Erkennen: Das ist eine endliche geometrische Reihe mit q = 1 + i. Die Summenformel für k = 0 bis n − 1 (also n Summanden) lautet:
    n−1Σk=0 qk = qn − 1q − 1 = 1 − qn1 − q   (Zähler und Nenner mal −1)
  4. q = 1 + i einsetzen. Der Nenner wird ganz einfach: (1 + i) − 1 = i.
    En = r · (1 + i)n − 1(1 + i) − 1 = r · (1 + i)n − 1i

Folie 04.11. „Endwert einer Rentenzahlung (Sparplan)“: Wird über n Perioden jeweils der Betrag r eingezahlt und mit Zinssatz i verzinst, so ergibt sich der Endwert En = r n−1Σk=0 (1 + i)k = r · (1 + i)n − 1i. Dies ist die Summenformel der endlichen geometrischen Reihe mit q = 1 + i.

3.3 Die Endwertformel anwenden RK

Beispiel 1: r = 100 €, i = 5 %, n = 3

  1. Werte als Dezimalzahl: r = 100, i = 0,05, n = 3.
  2. (1 + i)n = 1,053 = 1,157625.
  3. Minus 1: 1,157625 − 1 = 0,157625.
  4. Geteilt durch i: 0,157625 : 0,05 = 3,1525.

Darum gilt nur die endliche Formel; die unendliche Formel v01 − q gilt nur für |q| < 1. Ein Sparplan, der ewig läuft, wächst ins Unendliche. 3.4 Wie viel muss ich sparen? Formel nach r umstellen E

Oft ist das Ziel bekannt (z. B. 10 000 € in 5 Jahren) und die Rate gesucht. Dann stellt man En = r · (1 + i)n − 1i nach r um: beide Seiten mal i, dann durch ((1 + i)n − 1) teilen.

r = En · i(1 + i)n − 1

3.5 Ewige Rente: wenn die Reihe unendlich ist E

Hier wird die unendliche geometrische Reihe gebraucht. Frage: Wie viel ist es heute wert, ab nächstem Jahr für immer jedes Jahr r = 100 € zu bekommen (bei i = 5 %)? Geld in der Zukunft ist heute weniger wert: 100 € in einem Jahr entsprechen heute 1001,05 ≈ 95,24 €, denn 95,24 € würden in einem Jahr zu 100 € wachsen. Das heißt abzinsen.

Barwert = 1001,05 + 1001,052 + 1001,053 + … = ∞Σk=1 100 · (11,05)k
q = 11,05 ≈ 0,952 < 1 ✓, erstes Glied v0 = 1001,05
v01 − q = 1001,051 − 11,05 = 1001,050,051,05 = 1000,05 = 2000 €

5.1 Was ist eine Funktion? D

Eine Funktion f ordnet jeder Zahl x aus einer Menge D genau eine Zahl f(x) aus einer Menge Z zu. Man schreibt das in zwei Zeilen, genau wie auf Folie 62:

f: D → Z   x ↦ f(x)   Beispiel: f: ℝ → ℝ, x ↦ x2 + 1

Gelesen: „f geht von D nach Z, und x wird abgebildet auf x2 + 1“. Der Pfeil → steht zwischen den Mengen, der Pfeil mit Strich ↦ zwischen den Zahlen. Drei Mengen muss man auseinanderhalten:

BegriffBedeutungbei f(x) = x2 + 1, f: ℝ → ℝ
Definitionsmenge Dwas man einsetzen darf (links vom Pfeil →)ℝ, alle reellen Zahlen
Zielmenge Zwo die Ergebnisse landen dürfen (rechts vom Pfeil →); wird festgelegtℝ
Wertebereich (Bild) f(D)was wirklich herauskommt; muss man ausrechnen[1, ∞), weil x2 ≥ 0, also x2 + 1 ≥ 1

Zahlen dazu: f(0) = 1, f(1) = 2, f(−1) = 2, f(3) = 10. Die 0 liegt in der Zielmenge ℝ, kommt aber nie heraus. Also ist der Wertebereich kleiner als die Zielmenge. Das ist erlaubt, wird aber gleich wichtig.

  • Intervall-Schreibweise: [2, ∞) heißt „alle x mit x ≥ 2“ (eckige Klammer: 2 gehört dazu). (−1, 1) heißt „alle x mit −1 < x < 1“ (runde Klammer: Rand gehört nicht dazu). ℝ>1 heißt „alle x > 1“, also (1, ∞).
  • Keine Funktion wäre eine Vorschrift, die einem x zwei Ergebnisse gibt („x ↦ ±√x“) oder einem erlaubten x gar keins (1x bei x = 0, darum D = ℝ \ {0}).

5.2 injektiv, surjektiv, bijektiv DK

Bild mit Sitzplätzen: Die Studierenden sind die x (Definitionsmenge), die Stühle im Hörsaal sind die y (Zielmenge). Die Funktion sagt, wer auf welchem Stuhl sitzt. Jede Person sitzt auf genau einem Stuhl (sonst wäre es keine Funktion). Jetzt fragt man nach den Stühlen:

Begriffim Hörsaalin MatheWaagrechte-Linien-Test
injektivkein Stuhl ist doppelt besetztjeder Wert y wird höchstens einmal getroffen: x1 ≠ x2 ⇒ f(x1) ≠ f(x2)jede waagrechte Linie trifft den Graphen höchstens einmal
surjektivkein Stuhl bleibt leerjeder Wert y der Zielmenge wird mindestens einmal getroffenjede waagrechte Linie (auf Höhe eines y aus Z) trifft mindestens einmal
bijektivjeder Stuhl ist genau einmal besetztinjektiv und surjektivjede Linie trifft genau einmal

Zahlenbeispiel injektiv: Bei f(x) = x2 auf ℝ ist f(−2) = 4 = f(2). Zwei verschiedene x, derselbe Wert: nicht injektiv. Bei f(x) = 2x + 1 geben verschiedene x immer verschiedene Werte (f(1) = 3, f(2) = 5, f(3) = 7): injektiv.

Zahlenbeispiel surjektiv: Bei f: ℝ → ℝ, f(x) = x2 wird y = −4 nie getroffen (ein Quadrat ist nie negativ): nicht surjektiv. Bei f(x) = 2x + 1 findet man zu jedem y ein x, z. B. zu y = 8 das x = 3,5 (Probe 2 · 3,5 + 1 = 8): surjektiv.

Warum das wichtig ist: Nur wenn f bijektiv ist, kann man jedem y eindeutig sein x zurückgeben. Genau dann gibt es eine Umkehrfunktion f−1. Wäre ein Stuhl doppelt besetzt, wüsste man nicht, wen man zurückgeben soll. Wäre ein Stuhl leer, gäbe es dort gar niemanden.

5.4 Umkehrfunktion: das Rezept R

Die Umkehrfunktion f−1 macht f rückgängig: Wenn f die 3 auf die 10 schickt, schickt f−1 die 10 zurück auf die 3. Kurz: f−1(f(x)) = x. Achtung: f−1 heißt nicht 1f.

  1. Injektiv? Prüfen (waagrechte Linien). Wenn nein: D einschränken, bei Parabeln ab dem Scheitel.
  2. Wertebereich bestimmen und als Zielmenge nehmen. Dann ist f bijektiv. Der Wertebereich von f ist die Definitionsmenge von f−1.
  3. y = f(x) hinschreiben und nach x auflösen.
  4. Passendes Vorzeichen wählen, wenn eine Wurzel vorkommt (das ± entscheidet die Definitionsmenge von f).
  5. x und y tauschen, damit die Eingabe wieder x heißt: f−1(x) = …
  6. Probe: eine Zahl in f einsetzen, das Ergebnis in f−1: Es muss die Startzahl herauskommen.

Kleines Beispiel: f(x) = 2x + 1. y = 2x + 1 ⇒ y − 1 = 2x ⇒ x = y − 12 ⇒ f−1(x) = x − 12. Probe: f(3) = 7, f−1(7) = 62 = 3 ✓.

5.6 Monotonie und Beschränktheit von Funktionen DR

Das kennst du schon von Folgen (1.4, 1.5). Der Unterschied: Bei Folgen vergleicht man an mit dem nächsten Glied an+1. Bei Funktionen gibt es kein „nächstes x“, darum vergleicht man zwei beliebige Stellen x1 < x2.

BegriffBedeutungZahlenbeispiel
streng monoton wachsendx1 < x2 ⇒ f(x1) < f(x2): weiter rechts immer höher2x + 1: f(1) = 3 < f(2) = 5
streng monoton fallendx1 < x2 ⇒ f(x1) > f(x2)1x auf (0, ∞): f(1) = 1 > f(2) = 0,5
nach oben beschränktes gibt eine Zahl S mit f(x) ≤ S für alle x (Decke)xx + 1 ≤ 1 auf [0, ∞)
nach unten beschränktes gibt eine Zahl s mit f(x) ≥ s für alle x (Boden)x2 + 1 ≥ 1
beschränktnach oben und nach unten beschränktxx + 1 auf [0, ∞): 0 ≤ f(x) < 1

Die Methode aus der Vorlesung

  1. Erst Zahlen einsetzen (Wertetabelle). Daraus eine Vermutung machen: steigt? fällt? wohin geht es am Rand?
  2. Wenn möglich umschreiben (Polynomdivision, quadratische Ergänzung), damit man die Funktion besser sieht.
  3. Monotonie: x1 < x2 nehmen, die Differenz f(x2) − f(x1) auf einen Nenner bringen und (x2 − x1) ausklammern. Dann das Vorzeichen jedes Faktors prüfen. Alles positiv ⇒ wachsend.
  4. Beschränktheit: an den Rändern des Definitionsbereichs prüfen, was passiert (Zahlen nahe am Rand einsetzen). Läuft f dort gegen ±∞, ist es unbeschränkt. Bei einer monotonen Funktion liegen kleinster und größter Wert an den Rändern.

Mit Ableitungen (f′ > 0 ⇒ wachsend) geht Monotonie später schneller. Die kommen vermutlich erst am 02.12.

5.9 Grenzwert einer Funktion: Was heißt lim (x → a)? D

Ganz am Ende des 04.11. kam Folie 75: Grenzwerte von Funktionen. Das ist dieselbe Idee wie bei Folgen (1.6), nur dass x jetzt nicht 1, 2, 3, … durchläuft, sondern immer näher an eine Stelle a heranrückt.

limx→a f(x) = g   gelesen: „Wenn x ganz nah an a rückt, kommt f(x) ganz nah an g.“

Wichtig: Es geht um die Werte nahe bei a, nicht an a. Was genau bei x = a passiert, ist egal; f muss dort nicht einmal definiert sein. Genau das macht den Grenzwert nützlich: Bei x2 − 4x − 2 darf man x = 2 nicht einsetzen (Nenner 0), aber man kann fragen, wohin die Werte bei x = 1,9; 1,99; 1,999 laufen.

Einseitige Grenzwerte: von rechts und von links

  • x → 0+ (von rechts, „von oben“): x ist positiv und wird kleiner: 0,1; 0,01; 0,001; …
  • x → 0− (von links, „von unten“): x ist negativ und rückt an 0: −0,1; −0,01; −0,001; …

Stufe 4 · Prüfungsniveau Aufgabe FU9 · Prüfung: Parabel komplett untersuchen · eigene Aufgabe, Klausurstil wie Folie 62 · im Kapitel 5 Funktionen

Gegeben ist f: [1, ∞) → ℝ, f(x) = x2 − 2x + 3. a) Quadratische Ergänzung. b) Zeige: f ist streng monoton wachsend. c) Ist f beschränkt? d) Wähle die Zielmenge so, dass f bijektiv ist, und bestimme f−1 mit Probe.

Lösung Schritt für Schritt
  1. a) Hälfte von 2 ist 1, 12 = 1: x2 − 2x + 3 = x2 − 2x + 1 + 2 = (x − 1)2 + 2. Scheitel (1 | 2). Wertetabelle: f(1) = 2, f(2) = 3, f(3) = 6, f(4) = 11.
  2. b) x1 < x2, beide ≥ 1. f(x2) − f(x1) = (x2 − 1)2 − (x1 − 1)2. Mit a = x2 − 1 und b = x1 − 1 (beide ≥ 0, a > b) ist das a2 − b2 = (a − b)(a + b). a − b = x2 − x1 > 0 und a + b > 0 ⇒ Differenz > 0 ⇒ streng monoton wachsend.
  3. c) Nach unten: (x − 1)2 ≥ 0, also f(x) ≥ 2, Minimum f(1) = 2 ⇒ nach unten beschränkt. Nach oben: f(x) ≥ (x − 1)2 wird beliebig groß (f(101) = 10 002) ⇒ nach oben unbeschränkt. Insgesamt also nicht beschränkt.
  4. d) Wertebereich [2, ∞) ⇒ f: [1, ∞) → [2, ∞) ist bijektiv (injektiv wegen b). Auflösen: y = (x − 1)2 + 2 ⇒ y − 2 = (x − 1)2 ⇒ x − 1 = +√y − 2 (Plus, weil x ≥ 1) ⇒ f−1(x) = 1 + √x − 2, f−1: [2, ∞) → [1, ∞).
  5. Probe: f(3) = 6, f−1(6) = 1 + √4 = 3 ✓. f(4) = 11, f−1(11) = 1 + √9 = 4 ✓

  1. b) Monotonie: Die Tabelle fällt erst (4,25 → 2) und steigt dann (2 → 4,25) ⇒ auf (0, ∞) nicht monoton. Genauer, mit x1 < x2: h(x2) − h(x1) = (x2 − x1) · (1 − 1x1x2).
