## Organisatorisches (Kurs WI26A2)

Moodle-Kurs **„WI26A2: Infos für Studierende“** ([Kurs 18459](https://moodle.heilbronn.dhbw.de/course/view.php?id=18459)):
Vorlesungsplan, Prüfungsübersicht, Einführungspräsentation „Einführung Studienbeginn JG 26“, Phasenplan,
Rahmenstudienplan WI-DS, Krankmeldung, prüfungsrechtliche Regelungen, Richtlinien wissenschaftliches Arbeiten,
Portfolio-Postervorlage.

**Krankmeldung** (laut Dokument „Krankmeldung“ in diesem Kurs, gesehen 12.11.2026):
- Vorlesungen sind Pflicht. Bei Fehlzeiten **am ersten Tag vor Vorlesungsbeginn** per E-Mail an
  **sekretariat.wi@heilbronn.dhbw.de**, **Arbeitgeber in cc**, mit Name und Kursbezeichnung (WI26A2).
- **Ab dem 3. Krankheitstag** eine Kopie der Krankschreibung ans Sekretariat; das Original geht an den Ausbildungsbetrieb
  (§ 7.7 Ausbildungsvertrag).
- **Klausurtag:** vor Klausurbeginn telefonisch oder per E-Mail im Sekretariat melden, ärztliches Attest umgehend
  nachreichen; Merkblatt „Rücktritt von einer Prüfung aus wichtigem Grund“ beachten (Prüfungsamt:
  pruefungsamt@heilbronn.dhbw.de).
- Freistellungen nur in Ausnahmefällen, beantragt vom Ausbildungsbetrieb bei der Studiengangsleitung.
- Dateien einheitlich benennen: `WI26A2 Name Vorname_Datei`.

## Korrigieren

Stimmt etwas nicht (Thema verschoben, Termin ausgefallen, nur Übung), trag es im Abschnitt
**Eigene Notizen** im README des Fachs ein. Die Routine richtet sich beim nächsten Lauf danach.
